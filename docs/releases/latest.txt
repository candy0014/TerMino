Linux / Windows x64 最新发行版

包含当前单机挑战、Bot 对战、构造与地图挑战、最近 30 场回放、重复另存为及公网房间修复。

所有设置使用内置默认值。源码和发行包均不包含本地个人配置、地图/预设、挑战成绩或回放；它们仍保存在各自电脑的 .tetr 中。

Linux：下载 .tar.gz，完整解压后在终端运行 ./Play.sh。
Windows 10/11：下载 .zip，完整解压后运行 Play.bat，建议使用 Windows Terminal 和中文等宽字体。
Server.sh / Server.bat 可启动独立 UDP 服务端。

发行前执行 Linux 与 Windows 原生 Release 构建、完整 CTest、归档/SHA256 检查，以及中文和空格目录中的对局、回放、服务端启动检查。测试日志保存在对应 GitHub Actions 运行的 artifacts 中。

Linux 使用全静态运行库，Windows 使用静态 C/C++ 运行库。公网 WSS 仍需要系统可信 CA；Linux 键盘输入需要输入设备读取权限。49/99 Bot 等标有【测试】的挑战仍待长期性能与人工验收。

本轮原生 Windows 验证同时修正了 UNC 路径的分隔符一致性，以及短间隔等待与多人缩略图调度的计时精度；跨盘绝对回放路径继续保留为绝对路径。

升级前请备份自己的 .tetr。下载旁边的 .sha256 文件可校验压缩包。
