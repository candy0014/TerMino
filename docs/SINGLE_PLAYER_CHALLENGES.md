# 单机挑战：规则、成绩与录像

当前注册 **129 项固定挑战**（原有 30 项，新增 99 项），另动态加入本机地图的消除挑战和搭建挑战。
完整菜单树及稳定 ID 见 [SINGLE_PLAYER_CHALLENGE_CATALOG.txt](SINGLE_PLAYER_CHALLENGE_CATALOG.txt)。
设计依据保留在 [候选树](SINGLE_PLAYER_CHALLENGE_CANDIDATES_TECHMINO.txt)，实际数值以代码和当前目录树为准。

实现入口：`src/config/challenges.cpp`、`challenge_catalog.cpp`、`challenge_catalog_extended.cpp`、`challenge_config.cpp`、`challenge_prefix.cpp`；应用入口为 `src/app/single_player_challenges.cpp`。

## check：变量的集合和区间

check 读取**开局时实际运行的 RuntimeConfig**。它包含地图覆盖、模式转换、强制手感与 Bot 初始化后的值。
设置界面仅将 Settings 转为预计 RuntimeConfig，不能代替对局快照。val 同样只读取快照。

每个变量明确使用无限制、固定值、集合或区间；没有全局枚举大小比较，也不把 check 改成猜测难度的函数。
区间分别记录左右端点及是否包含端点，支持开区间、半开区间和无穷边界；实际变量必须是有限数。

| 情况 | 合法值 |
| --- | --- |
| 普通挑战不要求禁用暂存 | Hold 开关均可；QpNoHold 允许 `{0,1}` |
| 要求禁用暂存 | 实际 Hold 不可用；不把隐藏但实际启用的无限 Hold 当作禁用 |
| 最多 N 个 NEXT | `[0,N]` |
| 要求 Bot 至少 P PPS | `[P,+inf)` |
| 要求 Bot 搜索宽度至少 300 | `[300,+inf)` |
| 限定锁延最多 L 秒 | `[0,L]`；对应高速练习也禁止无限刷新 |
| 经典块等以指定手感为玩法核心的项目 | 对应手感使用固定值；加快或减慢均不自动视为合法 |
| 基础场高 20 | `[2,20]`；固定题面及特殊场地按各自尺寸检查 |
| 需要比较时间、且未另定重力的项目 | 下落间隔 `[0,1]` 秒/格，20G 也可通过 |
| 只关注块数、攻击效率等的项目 | 不追加上述通用重力上限；遵守该项自身规则 |

普通挑战允许关闭阴影、减少 NEXT、禁用额外操作或增加隐形限制。
旋转系统、场宽、随机规则、攻击公式、目标种类与目标数量会改变玩法或评分口径，按各项显式集合或固定值检查。
较高生存 APM 可以满足较低压力档。不同结束目标不混用成绩，避免延长对局刷攻击或全清数。
“更难即可通过”只用于项目明确规定的集合或区间。经典块的慢横移、缓降和等待本身属于难度，不能套用“越快越难”或“越慢越难”的全局判断。

**应用预设与 check 分开**：预设可以明确设置标准代表值，check 则接受其集合或区间内的值。
例如选择简单 Bot 会设置 0.7 PPS、宽度 300；自由游玩中对手为 1.2 PPS、宽度 400 时，也满足简单档。
对手的移动、暂存、场地、旋转和基础手感使用固定标准，不能通过削弱 Bot 的其它能力绕过速度、宽度检查。

## 菜单、预设和归属

挑战后显示最佳成绩或无记录；进入项目后，祖先选项框隐藏最佳成绩。
49/99 人 Bot 混战和仅听音挑战显示【测试】标签：前者尚待整局性能与难度校准，后者尚待声音设备兼容性和提示辨识验证。标签不改变稳定 ID 或已有成绩。
每项提供“成绩记录”“将设置修改为挑战标准”“开始此挑战”。连续两次回车开始时才启用显式违规终止。
浏览其它项目不会撤销预设。取消挑战、改用另一挑战时，从完整快照撤销选择之后的全部配置修改；人机挑战同时恢复双方。
保存玩家配置使用选择前快照，临时挑战配置不污染个人设置。

自由游玩结束后评估所有匹配项目。人机对战的胜利、失败均记录：胜利优先；胜利用时越短越好，失败生存越久越好。对手更强时可同时满足同玩法的多个较低难度档。
普通单窗口人人对战和公网联机不属于单机挑战；Bot 本人不写入人类成绩。
所有项目拒绝录像模式、模拟计时、时间倍率变化，以及整局使用过撤销或暂停的对局。

## 评分

统一保存三个数：`(progress, value, tie)`。
优先比较进度；其次比较该项指标；相同指标时可用更短时间区分。纯竞速用时相同不再比较冗余时间。
历史文件升级到 `TETR_CHALLENGES 2`，继续读取第 1 版记录，旧 PB 不删除。

| 项目 | 主要比较方式 |
| --- | --- |
| 竞速、攻击竞速、挖掘、高速与隐形 | 目标进度，再用时 |
| 40 行攻击效率 | 完成后才记录；实际攻击 / 实际总消行数，再用时 |
| 挖掘效率 | 完成后才记录；最少落块数，再用时 |
| 120 秒打分 | 活满时限才记录；分数优先 |
| 禅、经典练习 | 进度，再分数 |
| 无尽马拉松 | 总行数，再分数 |
| 生存、直列进攻 | 存活进度，再攻击数 |
| 散垃圾防守、定时涨垃圾 | 存活进度，再垃圾消除数 |
| 100 行全清 | 行数进度，再全清次数 |
| 连续全清 | 有效全清次数，再用时 |
| 固定全清题、三题题库 | 完成才记录；最少块数，再用时 |
| C4W 疯狂 | 连续消行的落块次数，首消算 1 次；再用时 |
| 秘密段位、棋盘格 | 最高完成层数，再首次达到该层数时的块数与用时 |
| 阶段任务大师 | 完成阶段数，再用时 |
| 单挑与回合制 Bot | 胜利优先；胜利比更短用时，失败比更长生存时间 |
| 地图搭建 | 逐格完全匹配后记录；用时越短越好 |
| 49/99 人 Bot 混战 | 名次，再攻击数 |

消行统计使用实际块型与次数，求和校验总消行数。场地构造使用块型对应关系，不读取用户自定义显示颜色。

## 逐块限制与最长有效前缀

每个匹配挑战独立创建 stopRule 状态。首次违规时，冻结**违规块之前**的完整结算数据、消行统计与时间；后续恢复合法也不延长前缀。
普通游玩继续；显式开始该挑战时在该块结算后立即结束，不生成下一块。
整局撤销、暂停计数仍使此前前缀失去记分资格。

已接入的限制包括：

- 科研：起链后的 B2B 中断；至少要有一次衔接。
- 科研+：消行必须 Spin 或全清，普通四消也受限。
- 只消四挖掘与纯消四：其它消行违规；极限纯消四不允许相邻四消重复列。
- TSD：仅非 Mini T-Spin Double；困难禁止连续四次同中心列，极限禁止与最近四次重复。
- 单消马拉松：仅普通单消，不能连续两块消行。
- C4W 疯狂：首次消行后每块必须消行；初始建形允许不消行。
- 连续全清：每个周期“累计消行 + 当前堆高”不得超过 4，全清后重置。
- 对称：消行后，镜像位置若都有方块，必须符合 I/I、J/L、O/O、S/Z、T/T 的块型关系；允许单侧空缺。
- 极简操作：本块实际输入数不得超过当前旋转、踢墙和障碍条件下的最少输入数；科研版还检查 B2B。

## 录像与保存

新录像在配置头保存各挑战的 `(ID, ruleVersion, 有效落块数, 游戏时间, 实际时间)` 边界。
挑战记录回放按落块序号截断，保留对应 EndPlace 后补 EndAll，结算与消行统计均由该前缀重新生成。
零块前缀不生成虚假的第一块；相同时间戳的多个落块不会导致多播。

旧录像缺少边界、缓存无效或版本变化时，`src/app/challenge_replay_analysis.cpp` 使用隔离上下文，提前执行真实落块、垃圾和计分流程，计算边界后再播放。
不会写个人配置或挑战记录。损坏、缺少结算标记的录像会拒绝分析。
原始完整录像保留，结束游戏或回放后可以多次另存为，前缀播放不会把原录像永久截短。
最近 30 场自动录像也关联到本局各项挑战记录，文件存在时显示 `Re`。过期且未显式保存的缓存自动删除，成绩保留，但不再显示 `Re`。
播放已有录像后另存为，会将当前玩家及本机另一玩家中引用该录像的成绩更新到最新保存地址；使用历史文件和 run ID 绑定，连续另存为和回放跳转不会丢失关联，也不会生成新成绩。

记录文件为玩家配置路径追加 `.challenges`，每项保留最近 10 次 PB 改进、其余最近 10 局和其余最近 30 条有录像的记录（含自动保存），最多 50 条，确保近 30 场缓存对应的成绩不会提前淘汰。
录像引用保存为项目相对路径；项目外可用 `../`，Windows 跨盘符保留绝对路径。输入与另存为仍接受电脑绝对路径。
地图、固定全清题和题库以内容、块序及版本绑定身份；修改题面会改变指纹。

## 新机制的项目规则

- 回合制 Bot：玩家每轮 1 块，Bot 每轮依次 0.3/0.5/0.75/1/1.2 块，使用原有支持小数额度的轮流出块机制；Bot 预设 2 PPS、搜索宽度 300。check 要求对应额度及 PPS/宽度下限。新挑战使用 `local-bot-chatgpt-turn-*` ID，与旧七块回合制成绩分开，历史文件不删除旧记录。
- 构造点阵：秘密段位显示大于号形状及顶盖，棋盘格显示目标奇偶格，对称项目提示已落方块的空缺镜像位置；使用与出块点提示相同的点阵绘制，不改变场地、碰撞或统计。移动、旋转、阴影、擦除、重绘、撤销和录像恢复目标提示。自由游玩仍可评估原有构造项目。
- 构造与图形 → 地图：列出本机地图，有成绩优先，再按编号。开局为空场，仅采用地图宽高和占用形状；颜色、块序、旋转、原完成目标和初始楼层均不导入。搭建时保留满行；每格占用状态必须完全一致，隐藏区也不能有额外方块。空地形在开局即已匹配。目标形状嵌入原生录像，不依赖后续地图文件。挑战指纹只随尺寸和形状变化，不随地图颜色、名称、块序或原目标变化。
- 高速经典四档：统一使用项目“经典块”固定手感，按 60.0988 Hz 换算：DAS 16 帧、ARR 6 帧、固定缓降每格 2 帧、DCD 0、无预移动、无 DAS 预充、进块 10 帧、消行 17 帧；禁止硬降和 180°旋转。初始下落间隔固定为 0.8/0.3/0.1/0.03 秒，锁延固定为 0.5/0.3/0.15/0.08 秒，刷新次数固定为 5/5/5/0，关闭无限刷新和 20G；每 10 行按 NES 曲线加速。预设与 check 使用相同固定标准，原先的 20G 和强制手感不能残留或绕过检查。NEXT 仍允许 0–1。
- 挖掘：垃圾行混乱度固定为 1；有限垃圾消除目标只生成目标所需行数。已消除数加场内垃圾数达到目标时停止补行；接近目标时只补缺额，初始垃圾也受目标上限限制。历史回放继续使用原先记录的上涨事件。
- 干旱：每袋含除 I 之外的六种块，各一次，持续洗袋。
- 干旱+：0 NEXT；逐块考察各候选的最佳简单下落结果，按高度、空洞、崎岖和消行评分，提供最不利候选。
- 本能：20G；当前块出生后显示 0.2 秒，随后隐藏，锁定场地保持可见；无阴影。
- 全盲：隐藏当前块与锁定场地，0 NEXT、无 Hold、无阴影。
- 听音：采用全盲显示；出生三音的中音区分块型，移动两音表示列与朝向，结算提示消行并从左到右播放列高。Linux 使用 PulseAudio，Windows 使用 Beep。
- 全清题库 v1：O、I、需旋转的 T 三个独立识别题；解完自动换题。首题、全部题库的内容分别参与身份指纹。
- 阶段任务大师：20G，依次完成 10 行、2 次四消、2 次 Spin 消行、1 次全清；锁延依次为 0.8/0.5/0.25/0.12 秒。阶段状态随新局重置。
- Stack：未凑足 4 个满行时保留满行；达到 4 行后统一消除、坍塌与计分，目标 100 行。
- 极简操作：无自然重力、无 Hold，DAS=0.1、ARR=0、无预移动；固定缓降。按键计数包括平移、旋转、缓降和硬降，自动重复不重复记按键。最短路包含单移、移到墙、实际踢墙、可释放的缓降和最终硬降。计数写入录像并在回放恢复。
- Bot 混战：48/98 个独立 bot_chatgpt；默认 0.7 PPS、宽度 300，自动随机攻击存活目标，无徽章与命数。后台并发搜索，主线程提交落块和垃圾；原生录像记录人类场地、收到的攻击和剩余人数。机器算力会影响大量 Bot 的实际搜索吞吐。

## 验证范围

`challenge_catalog` 覆盖所有目录定义可应用、区间开闭边界、资格范围、评分与历史升级、真实消行/Stack/阶段推进、三题自动切换、旧录像预分析、极简输入录像、干旱随机、隐形计时，以及 49/99 人场景中的真实并发 Bot 落块。
其它回归继续覆盖人机归属、菜单、地图、统计、录像与配置保存。
Bot 与构造回归覆盖失败成绩落盘、胜负排序、五档小数回合额度和 2 PPS、空场搭建、地图额外参数隔离、形状身份稳定、真实落块完成、额外/缺失/隐藏格拒绝、满行保留，以及删除原地图后的完整录像播放。终端绘制回归覆盖两种方块样式、隐藏颜色、目标点阵的移动擦除和撤销恢复。
经典手感回归覆盖四档准确值、加快和减慢均拒绝、20G 残留修正、强制缓降的数值及计时方式、个人手感回滚，以及运行时手感不符时拒绝计分。
挖掘补行验证覆盖最后 10 行的真实落块消除、目标前部分补行、低于初始层高的目标和旧录像事件；录像回归覆盖 30 场轮换、自动录像 `Re`、连续另存为、跳转后另存为，以及缓存过期后的 `Re` 移除。
这不等于完成了每个挑战的人工通关，也不等于已经完成 49/99 人混战整场的性能校准或声音设备试听。
