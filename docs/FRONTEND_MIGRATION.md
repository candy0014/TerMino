# 终端与 OpenGL 前端迁移和维护方案

TerMino 保留现有终端版的全部内容，在同一仓库、同一游戏核心上新增 OpenGL 前端。Linux 和 Windows 均需方便地分别构建终端版与图形版，并从同一源码提交统一发布。迁移前的提交、标签、备份与回退方法见 [Git 基线](FRONTEND_BASELINE.md)。

## 必须满足的产品要求

- 终端版的所有内容持续保留：完整玩法和模式、旋转与随机系统、全部挑战、参数与键位、预设、地图及编辑器、所有 Bot、模拟与回合制、本地双人、UDP/WSS 房间、观战、房主管理、回放及分析、成绩、命令行入口、测试与工具。内部重构和文件移动不得缩减能力。
- 图形版最终覆盖终端版所有用户可操作的内容和全部键盘操作。启动、菜单、设置、改键、文本输入、地图编辑、房间、观战、对局、暂停、撤销、重试、回放与另存等流程均可在没有鼠标设备时完成。鼠标按钮、点击、拖动和滚轮提供等价快捷入口，不能成为唯一入口。
- 两端共用游戏规则、时间语义、参数校验、挑战判定、Bot、网络协议和数据格式。显示方式可以不同，信息与可操作能力需等价。图形版未完成全功能与全键盘验收前明确标为预览版。
- 图形风格采用深色科技感界面、冷色高亮、清晰方块与层次分明的面板。酷炫主要来自布局、配色、字体、边框和克制的菜单过渡。游玩过程中优先辨识与低延迟；首版不加入大面积粒子、屏幕震动、拖尾、全屏闪光或持续遮挡棋盘的动画。
- 本地 `.tetr` 完整保留。发布包以干净源码和默认初始配置生成，不上传个人数据。

图形界面的视觉基准为深蓝黑背景、青色主强调、紫色次强调和高对比正文；键盘焦点用清晰描边与文字状态同时表示。面板留白、网格对齐和字体层级承担主要视觉效果。棋盘保持稳定，沿用块型与垃圾的语义颜色，保留原有外观选项；隐形和伪装挑战优先于皮肤。首版仅保留短促、可关闭的状态反馈，不让动画阻塞输入或遮住出生区、落点和垃圾条。

## 全键盘验收

| 流程 | 无鼠标验收要求 |
| --- | --- |
| 启动与菜单 | 可见焦点，方向键与 Tab/Shift+Tab 导航，确认、返回及原有快捷键可用 |
| 设置与改键 | 可到达每个设置、调整数值、选择选项、恢复默认、捕获及释放原有全部按键 |
| 文本与路径 | 中文输入法、编辑、确认、取消以及手动输入文件路径；不能仅提供鼠标文件选择按钮 |
| 地图和预设 | 选择、创建、命名、编辑、保存、应用和删除均有键盘路径，保留原编辑器全部键盘操作 |
| 联网和观战 | 地址与房间输入、加入、准备、开始、观战、房主管理及返回流程均可用键盘完成 |
| 对局和回放 | 原有游戏键位、双人键位、暂停、撤销、重试、设置、回放控制及另存全部保留 |
| 焦点与弹窗 | 关闭弹窗能恢复到原焦点；输入框中的按键不误触游戏；失焦和恢复不遗留按下状态 |

测试时断开或禁用鼠标，仅用键盘完成上述流程。自动化脚本覆盖焦点顺序、激活、取消和返回，实机验收覆盖输入法、窗口切换及键盘设备。鼠标功能必须调用对应的共享命令。

## 目标模块边界

| 模块 | 职责 |
| --- | --- |
| Runtime 和 Rules | 语义状态、几何、随机数、移动、旋转、攻击、消行与时间规则 |
| Engine 和共享应用层 | 会话调度、挑战、Bot、回放、联网、存档、菜单与编辑命令 |
| Presentation | 只读视图、可见性、统计与带时间戳的语义事件 |
| Terminal frontend | ANSI、字符布局、终端生命周期、原生键盘、终端重绘缓存 |
| OpenGL frontend | SDL 窗口和事件、OpenGL 绘制、字体资源、缩放和鼠标入口 |
| Headless tests | 不创建终端或窗口的核心、视图及前端契约回归 |

前端提交 `GameCommand / UiCommand`，消费 `ViewSnapshot / PresentationEvent`。共享接口使用语义 ID、游戏坐标、时间和值，不携带终端坐标、ANSI、SDL、GL 对象或指向可变菜单对象的跨线程指针。隐藏规则由共享 Presentation 计算，实时隐藏单元格不能通过视图泄露原方块。

保留已有的 Runtime、Rules、Engine 分层约束。新增无平台 Presentation 库；回放、远端和完成时间的适配放在独立 context adapter 中。终端差量绘制和 OpenGL 绘制使用相同可见性规则。终端输出函数逐步通过适配层迁移，不能在核心中新增 `if terminal / if OpenGL` 的两份规则。

## 输入和调度

SDL3 处理窗口、键盘、输入法和焦点，OpenGL 3.3 Core 作为图形最低基线，glad 加载函数，FreeType 提供字形缓存。固定依赖提交或版本、下载哈希、生成参数和许可证；图形依赖仅在图形目标启用时查找。

原生 Windows/evdev 和 SDL 输入分别接入同一动作系统。动作带玩家、按下或释放、时间戳、顺序号；DAS、ARR、软降、预输入和按键优先级继续由共用引擎处理，忽略系统自动重复。SDL 时间戳适配到同一单调时间轴，文本输入与游戏动作分离。菜单使用完整的方向键、Tab、确认、返回和快捷键焦点导航；进入文本框和切换界面后不能遗留游戏按键。

SDL 事件和 OpenGL 由主线程拥有；最终会话调度器是游戏状态的唯一写入者，通过队列收命令、发布不可变快照。每个玩家可独立读取同一物理事件历史。网络与 Bot 的工作结果经有序边界进入会话。

游戏推进、锁延、消行等待、进块、垃圾和网络调度不由显示帧率或交换缓冲驱动。先保留现有计时和回放标记语义，再逐步把阻塞循环提取为可推进的会话状态机。渲染落后可以合并画面，不能丢失输入、规则事件或网络协议事件。菜单和等待期间持续响应键盘及窗口事件。

## 数据兼容

继续使用现有玩家文件、地图、预设、挑战历史、最近回放和录像格式。窗口、缩放、帧率、着色器等配置另存图形配置文件；SDL 的物理键位另存，保留现有平台键位。存档服务集中处理旧格式、原子替换、同档案双开写锁和冲突检测。格式升级必须提供旧文件用例和可恢复迁移，不自动清空个人目录。

## 构建和发行

保留 `tetr`、`tetr_ft7`、`tetr_server` 及现有默认脚本。最终新增 `tetr_gl`，提供终端、图形、双端、服务端和无界面测试配置。CMake 开关为 `TETR_BUILD_TERMINAL`、`TETR_BUILD_OPENGL`、`TETR_BUILD_SERVER`。默认构建继续生成完整终端版。

第一阶段提供 terminal/headless/server 配置。第二阶段已新增可工作的 `tetr_gl` 和 OpenGL/both 配置，Bash/PowerShell 入口支持 `terminal / opengl / both`。具体命令、依赖和阶段限制见 [OpenGL 预览说明](OPENGL_PREVIEW.md)。

| 平台 | 正式目标 | 独立验证 |
| --- | --- | --- |
| Linux | 终端版 | 不安装图形依赖可编译、测试、运行 |
| Windows | 终端版 | 原生工具链编译，完整键盘与控制台行为 |
| Linux | OpenGL 版 | 无需终端输入设备权限，全键盘、X11/Wayland 和高 DPI |
| Windows | OpenGL 版 | 原生窗口、全键盘、中文输入、DPI 和显卡驱动 |

终端包保留当前静态运行库方案。GUI 单独确定系统库兼容基线，依赖系统图形驱动，随包附带所需资源、许可证和运行库。一个版本标签对应同一提交，四个平台/界面组合全部验证通过后才发布为正式最新版；清单记录提交和回放/网络兼容信息。

## 同步维护要求

新增规则和功能先修改共享实现，再补齐两个前端的入口、展示和键盘操作。新增设置通过共享 schema 和菜单模型生成；新增挑战从同一注册目录进入两端。只有视觉效果可以标记为前端专属。功能完成的含义包括两端能力和兼容性验收。

每个变更说明共享影响、终端影响、图形影响、键盘路径、数据兼容、验证和回退点。同一 `main` 维护短期功能分支，迁移提交保持可独立回退。工程约定见 [维护规则](../CONTRIBUTING.md)。

CI 在 Linux/Windows 构建并测试两端；核心测试每个平台运行一份，分别增加前端冒烟和隔离配置。固定随机种子、时间戳输入、Bot 决策及网络事件，在不同呈现频率和无呈现情况下比较语义状态、攻击、成绩和回放。渲染测试比较各自基准，跨显卡不要求像素完全相等。补充混合前端联网、录像交叉播放、全键盘路径、失焦恢复、输入法、高 DPI、中文和空格路径、默认发行数据检查。Linux 可用 Mesa 软件渲染，Windows 需要有效 OpenGL 环境并保留真实显卡验收。

## 第二阶段实现

新增真实 `tetr_gl` 程序：SDL3 主线程管理窗口、事件与 OpenGL 3.3 Core，glad 加载函数，FreeType 字形图集绘制文本。使用深色网格、青紫边框、清晰键盘焦点和稳定方块，没有高干扰特效；窗口按比例缩放。

`Graphical::Session` 是过渡会话适配器。工作线程独占原 `App::initialize_game / App::run` 及其 Runtime、Replay、Input、Undo 和 Pause 状态；SDL 输入注入已有事件缓冲，通过原 `BindingSet` 解释。SDL 纳秒事件映射到同一个 steady clock，规则仍使用原时钟。渲染线程只读取值快照，绘制频率不能推进规则或覆盖待处理输入。

本阶段仅新增两个应用 UI 端点（打开设置、对局完成）；未挂接时仍进入原有完整终端流程。图形会话临时链接旧终端呈现库并关闭 ANSI 输出，回放定位不能重新开启输出；不创建 TerminalSession、不读取 evdev 或 Windows 全局键盘。完整非阻塞会话状态机和终端缓存抽离仍在后续完成，不将这一过渡桥接描述成已完全解耦。

已开放基础单人游玩、Hold/Next/Ghost、基本统计、暂停、撤销、重试、结束保存、单棋盘回放暂停/速度/定位和键盘路径输入。默认预览不写配置，可显式只读导入原平台档案，录像继续使用原编码/校验与目录规则。完整设置、地图编辑、预设、136 项挑战界面、所有 Bot 入口、联网/观战、双人和统计页必须在第三阶段逐项完成；终端能力基线和全部入口继续保留。

构建新增 Linux/Windows 的 opengl/both 预设、脚本选择及只安装图形程序与资源的 `OpenGLPreview` 组件。图形依赖仅在图形开关打开时查找；无界面和终端默认构建不引入图形包。新增原生 Windows 编译/无窗口测试和 Linux 两端/软件 OpenGL 冒烟 CI；本地实际执行结果单独记录，不把 CI 配置等同于 CI 已运行。
