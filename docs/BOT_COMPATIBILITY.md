# BOT 规则兼容性

判断入口为 `Autoplay::availability`；每个 BOT 的 `availability` 返回可用状态和具体原因，设置菜单与初始化共用这些判断。未启用的快速游戏 Mod 不影响其他模式的判断。

统一路径搜索 `Bot::getop` 与动作执行共用位移函数：

- 普通 ARR、ARR=0 和零 DAS 的滑动都遵守碰撞；20G 或按住无限软降时，每横移一格后立即落到底，再判断下一格。
- 支持本帧先旋转、再横移，但单格横移与强制落底不可拆开；零 DAS 的重复也不能先连移两格再落底。
- 公共路径搜索、While1 和 Cold Clear 的 20G 搜索共用动作筛选与执行规则，逐格记录横移和下落。
- 无限软降只生成到底操作；有限自然重力可用等待一格下降，等待期间继续处理帧事件。
- 搜索和执行均遵守禁用左右、旋转、软降和硬降。
- 搜索和脚本重建都检查复合动作的方向与旋转限制。禁用软降只禁止软降输入，普通重力的 `V` 和 20G 落底仍可用。禁用硬降时，以触底后的 `W` 等待自然锁定结束，保留锁定延迟且不增加降落分数；关闭自然重力时无法锁定，搜索返回无路径。`W` 不产生硬降输入，`H` 始终只表示允许的硬降。
- 路径终点要求坐标、朝向和最终 Spin 分类一致；按本局 Spin 奖励及 QuickPlay 规则判断，无 Spin / Mini / 完整 Spin 相同的踢墙记录可以互换。执行与回放保留真实路径记录，不覆写成 BOT 的踢墙编号。
- BOT 的候选目标均经过路径验证，包含不播放动作动画的高 PPS 模式。默认执行中不可达目标改用当前方块的合法硬降；ChatGPT 手感模拟保留策略选定的目标并核对最终姿态，场地变化时重新规划。
- 新旋转系统的方块编号按族名送入策略，保留真实方块定义与旋转规则；返回给游戏的是原编号。

快速游戏的 `while1`、`zzztoj_botris` 和 `chatgpt` 已支持各类正常 / 逆位 Mod、特殊方块、雪球成长、20G 和零 DAS，使用主程序的攻击、抵消、重复惩罚及推进器规则；详见 [Quick Play BOT 适配](BOT_QUICK_PLAY_MODS.md)。上表的历史限制仍适用于各自的原搜索入口。`candy0014` 不支持快速游戏重力增长及尚未模拟的场地 Mod；`mech` 和其他 zzztoj 策略仍报告快速游戏不可用。

隐藏颜色、界面层级、方块样式、禁用撤回和回放撤回统计不改变 BOT 的可达性。有限软降、固定软降、DCD、锁定配置与按落块 / 轮流计时由引擎处理；路径搜索检查其影响动作几何的零值和无限值。BOT 暂时仍使用每块至多一次暂存的策略接口，因此多次暂存明确报告不可用。

攻击规则新增的 B2B 奖励 / 充能、全消和半消奖励由 ChatGPT 与 Cold Clear 共用游戏规则结算，预测中独立保存放置方块的格子并随消行压缩；占用相同但格子来源不同的局面不会合并。While1 和 Botris 的快速游戏入口同样使用本局攻击规则；其原搜索入口和其他 zzztoj 策略要求默认攻击规则。Candy0014、Mech 的场地 / 固定方案仍由引擎结算攻击。

`chatgpt` 的「手感模拟」是落点确定后的路径展示。思考使用独立快照，普通重力下活动方块保持不动；20G 在出生及每次移动 / 旋转后落底，Hold 已知目标可先执行首次缓冲操作。开启与关闭均使用普通候选及评分；统一 `Bot::getop` 搜索到选定落点的几何路径，遵守碰撞、旋转、动作限制和 20G。路径耗时仅决定展示节奏，不参与候选筛选或评分。展示不驱动虚拟按键、不推进周期重力和自然锁定计时，不依赖预充能或锁定重置历史。开局保留 ChatGPT 的配置重力，供几何可达性和 SDF 计算。执行保留首次目标及 Spin 分类，Hold 延续同一目标，完成后核对终点并保留实际踢墙记录。PPS 的剩余等待在无活动方块时进行。其他 BOT 开启该选项会明确报告不支持。

有限软降在实际展示和回放中逐格按当前 SDF 计时；横向连移按当前 DAS / ARR 呈现，硬降瞬间落地。
