本版采用的原则
├─ Techmino 用来提供挑战思路和难度方向，不以完整复刻它的机制为准入条件。
├─ 旋转、Spin 判定、B2B、攻击、抵消、分数和垃圾回灌，统一使用本项目的挑战标准。
│  不因缺少 TRS、原版 B2B 气槽、攻击表、首包优化或渐隐动画而搁置已有玩法。
├─ 固定本项目影响成绩的规则与倍率，保留允许范围内的个人旋转系统和普通手感选择。
│  个别挑战的核心恰好是手感/旋转限制时，再固定相应参数；不能靠调高攻击倍率刷成绩。
├─ 难度保留在实质限制上：更少信息、更快重力、更短锁延、更强垃圾压力、更严格消除条件。
│  下面的新档位、目标和具体数值是设计草案，需在本项目试玩校准；不是已验证的难度等价。
│  不直接使用 Techmino 的分数评级、通关时间或波次数字，作为本项目达标门槛。
├─ 按玩法组织树，不另拆一棵“原版”与一棵“项目变体”；每个挑战只规定一套明确的本项目规则。
└─ 保留已有 20 项及其历史成绩；新增候选只补缺项。仅因参考游戏的差异，不改动现有 PB 规则。

实现标记
├─ [已有]：本轮之前已注册的挑战。
└─ [已实现]：本轮新增的配置、逐块判定或玩法机制；均已注册到菜单。
   原设计提出的压力档保留为本项目参数，仍可通过实际试玩继续校准。

单机挑战候选树
├─ 1. 竞速
│  ├─ 标准竞速
│  │  ├─ 10／20／40／100／1000 行 [已有]
│  │  └─ 400 行 [已实现]
│  │     达到目标行数后比较用时；普通重力、常规暂存与预览，沿用现有竞速标准。
│  ├─ 特殊方块集
│  │  ├─ 五连块 40 行 [已有]
│  │  └─ 一至三连块（M123）40 行 [已实现]
│  │     使用项目已有对应方块集；不要求它们的旋转方式与 Techmino 相同。
│  ├─ 操作受限
│  │  ├─ 无旋转 40 行 [已有]
│  │  │  禁止全部旋转操作；不能拿“无踢墙”替代“无旋转”。
│  │  ├─ 无移动 40 行 [已实现]
│  │  │  禁止左右平移，允许旋转踢墙带来的位移；使用本项目允许的旋转系统。
│  │  └─ 无摩擦 40 行 [已实现]
│  │     核心为 20G、DAS=0、ARR=0；Next 数与锁延采用本项目统一标准，不追原版精确值。
│  └─ 信息受限
│     ├─ 无预览 40 行 [已实现]
│     │  7-BAG、0 Next，保留普通 Hold，重点考察临场决策。
│     ├─ 无预览且无暂存 40 行 [已实现]
│     │  7-BAG、0 Next、关闭 Hold。
│     └─ MPH 40 行 [已实现]
│        独立随机（TOTAL MAYHEM）、0 Next、关闭 Hold；保留“无法依赖袋规律与储备信息”的难点。
│
├─ 2. 攻击与效率
│  ├─ 100 攻击竞速 [已实现]
│  │  使用本项目攻击表与累计产生攻击数，达到 100 后比较用时；不要求真的把攻击送给对手。
│  │  默认使用本项目普通 Hold；若以后增加无限 Hold 的思考练习，另列规则，不强行照搬原版。
│  ├─ 40 行攻击效率 [已实现]
│  │  APL=累计产生攻击/实际总消行数；完成 40 行后，APL 高者优先，同值用时短者优先。
│  │  最后一块超过 40 行时按实际消行数计算。正式榜仅收达标局，避免残局高 APL 占榜。
│  ├─ 科研：不断 B2B 的 100 攻击 [已实现]
│  │  ├─ 普通：低重力、宽松锁延，主要考察堆叠与连续高阶消除。
│  │  ├─ 困难：普通重力与锁延，增加操作时间压力。
│  │  └─ 疯狂：20G，在压力下保持 B2B。
│  │     按本项目 B2B 连续规则判定；至少完成一次 B2B 衔接，且整局 b2bBreaks=0。
│  │     起链前的普通消行允许；起链后的断链不允许。不需要新增原版 0..1000 气槽。
│  │     现有 b2bExtensions/b2bBreaks 可用于结算验证；三档用不同 ID 与规则记录成绩。
│  ├─ 科研+：仅 Spin 或全清的 100 攻击 [已实现]
│  │  ├─ 普通：低重力、宽松锁延。
│  │  ├─ 困难：普通重力与锁延。
│  │  └─ 疯狂：20G。
│  │     每次消行必须为本项目判定的 Spin 或同时达成全清；普通四消未全清也不合格。
│  │     不消行落块允许。需逐块保存“本次消行是否为全清”，累计消行表本身不够。
│  └─ Backfire 自攻：100 攻击 [已实现]
│     ├─ 普通：缓冲等待 2 秒。
│     ├─ 困难：缓冲等待 1 秒。
│     ├─ 疯狂：缓冲等待 0.5 秒。
│     └─ 极限：缓冲等待 0 秒。
│        直接沿用项目现有“抵消后剩余攻击回灌自己”的行为，保留进攻、抵消和生存的取舍。
│        入场方式、垃圾盖帽与形状固定为本项目标准；零等待不自动等于任意时刻立即上涨。
│        上述等待是待试玩的压力档，不要求回灌顺序或每包攻击量与 Techmino 相同。
│
├─ 3. 打分与长局
│  ├─ 120 秒限时打分 [已实现]
│  │  固定普通重力，使用本项目分数规则；活满 120 秒后分数高者优先。
│  │  与重力逐渐上升的加速打分分开，不强制原版最低 ARR 或消行动画时长。
│  ├─ 120 秒加速打分 [已实现]
│  │  采用项目已有 Blitz 递增重力；同一时限下处理更强的速度压力，以分数排名。
│  ├─ 禅 200 行 [已实现]
│  │  无总时限、关闭自然重力、宽松锁延；以 200 行内分数为主要成绩。
│  │  定位为思考与效率练习，可允许无限 Hold；不纠结原版使用 2 秒下落还是网页写的无重力。
│  └─ 无尽马拉松 [已实现]
│     无固定消行终点，采用本项目递增重力，达到现有速度上限后保持；按总消行数、分数排名。
│     保留耐力与长局管理的挑战，不要求复刻原版 1700 行终点或后段锁延表。
│
├─ 4. 挖掘
│  ├─ 挖掘竞速
│  │  ├─ 10／20／40／100 行 [已有]
│  │  └─ 400 行 [已实现]
│  │     统一沿用当前保持 10 层单孔垃圾的玩法；挖掉目标数量后结束、用时短者优先。
│  │     不再为了原版的初始清空或尾段停止补层，新增另一套垃圾预算系统。
│  ├─ 挖掘效率：10／20／40／100／400 行 [已实现]
│  │  同一垃圾规则下，完成目标后落块数少者优先，再比较用时；不是 APL。
│  │  允许低重力和宽松锁延；是否允许无限 Hold 作为该组固定规则，不沿用所有挑战的公共限制。
│  ├─ 只消四挖掘：10／40 行 [已实现]
│  │  挖掘目标仍统计垃圾行，但所有消行都必须是四消；允许不消行的落块。
│  │  第一阶段可通过结算消行表验证整局条件；若要“违规立即结束”，再补逐块规则。
│  │  使用现有持续补层，最终一次超过垃圾目标按达到目标处理，无需还原原版有限题面。
│  └─ 定时涨垃圾生存 [已实现]
│     ├─ 普通：每 3 秒直接上涨 1 行。
│     ├─ 困难：每 2 秒直接上涨 1 行。
│     └─ 极限：每 1 秒直接上涨 1 行。
│        沿用 CheeseTimer，不可用攻击抵消；以存活时间为主、挖掘行数为次。
│        与可抵消的 APM 生存区分；先用固定间隔保留速度难度，动态加速可后续再加。
│
├─ 5. 生存、进攻与防守
│  ├─ 标准 APM 生存
│  │  ├─ 40／60／100 APM × 1／3／5 分钟 [已有，共 9 项]
│  │  └─ 150／200 APM × 1／3／5 分钟 [已实现]
│  │     保留当前“进度优先、达标后攻击数优先”的评价；高难参数需实测可玩性。
│  ├─ 直列进攻练习 [已实现]
│  │  ├─ 普通：中等来袭压力、较长抵消等待。
│  │  ├─ 困难：提高来袭压力，缩短等待。
│  │  └─ 极限：高压力、短等待。
│  │     使用项目 Survival，降低包内孔洞变化，鼓励利用直列垃圾组织攻击、反击和抵消。
│  │     建议统一 180 秒目标；先比较存活进度，再比较累计产生攻击。具体 APM/等待待试玩定档。
│  │     不要求“每组至少 20 行”“清掉一组再来下一组”，因此不依赖原版波次调度器。
│  └─ 散垃圾防守练习 [已实现]
│     ├─ 普通：中等压力、较长抵消等待。
│     ├─ 困难：更强压力、更短等待。
│     └─ 极限：高散度、高压力、短等待。
│        使用较高孔洞变化率，重点是维持地形、快速挖掘和稳定抵消；统一 180 秒目标。
│        排名先比较存活进度，再比较挖掘行数；无需与原版波数、难度名称逐一对应。
│        进攻/防守应固定垃圾散度、盖帽、入场方式和抵消倍率，不能只在菜单上改一个名称。

│  │  ├─ 普通：本项目 Marathon 重力曲线，逐渐加速。
│  │  └─ 困难：固定 20G 与统一锁延，持续高速处理地形。
│  │     完成目标后用时短者优先；不为复刻 Techmino 速度表、首包和阶段点另加机制。

│  │  ├─ 进阶：200 行，标准锁延，减少预览。
│  │  ├─ 大师：200 行，短锁延，继续减少预览，可关闭 Hold。
│  │  └─ 终点：200 行，短锁延且不允许移动/旋转刷新锁延。
│  │     保留高速、操作容错变小和信息减少的难度；不要求 TGM Level、骨块、段位和字幕考试。
│  │     拟从锁延 0.8／0.5／0.25／0.12 秒试玩，Next 从 5 向 1 递减；不是已校准参数。
│  ├─ 策略堆叠 [已实现]
│  │  ├─ 简单：20G，短锁延，较长 ARE，可提前规划。
│  │  ├─ 困难：缩短 ARE，压缩每块决策时间。
│  │  ├─ 极限：进一步缩短 ARE，保留极短落地锁延。
│  │  └─ 各档无 Hold 版本：在同档速度下额外禁用暂存。
│  │     目标 200 行；可固定 ARE，不要求按行数复刻动态阶段表。
│  │     以 ARE 约 1／0.5／0.25 秒、锁延约 0.12／0.10／0.08 秒为初始试玩参数。
│  ├─ 小场地马拉松：5×10 [已实现]
│  │  ├─ 普通：目标 200 行，普通/递增重力。
│  │  └─ 困难：目标 200 行，高重力或 20G。
│  │     直接使用项目实际场宽、场高；保留容错空间小的核心，不必生成原版侧墙。
│  └─ 高速经典练习 [已实现]
│     ├─ 简单：NRS、CLASSIC 随机、无 Hold、1 Next、无阴影，低初速的 NES 曲线。
│     ├─ 困难：同规则，提高初始下落速度。
│     ├─ 疯狂：更高初速，压缩地面调整时间。
│     └─ 极限：极高速度与更小锁延容错。
│        可统一 200 行目标，达标后按分数排名；不要求复制 NES 的逐帧行为和起始等级编码。

│        经典慢手感是玩法本身：DAS/ARR、缓降、预移动/预充、进块和消行等待均使用固定值；不以更快或更慢代替该标准。

├─ 7. 隐形与记忆
│  ├─ 半隐 200 行 [已实现]
│  │  锁定约 5 秒后直接消失；保留当前块和阴影，作为记忆挑战入门。
│  ├─ 全隐 200 行 [已实现]
│  │  锁定约 1/3 秒后消失；不要求渐隐动画，保留短暂确认位置的窗口。
│  ├─ 瞬隐 200 行 [已实现]
│  │  锁定即隐形，保留当前块和阴影。
│  ├─ 瞬隐+ 200 行 [已实现]
│  │  锁定即隐形且关闭阴影；按进度与用时排名，使用统一的本项目手感/重力标准。
│  ├─ 周期闪现隐形 200 行 [已实现]
│  │  场地平时不可见，每隔固定时间短暂显示；间隔越长、显示越短，记忆压力越高。
│  │  与延迟消失类分开，不把周期闪现误作上述“半隐”。
│  ├─ 本能：20G 当前块隐形 [已实现]
│  │  当前块生成后短暂可见，随后隐藏，锁定后恢复为可见场地；核心是快速识别与盲操。
│  │  需新增当前块可见性及生成后计时，不能只把已锁定场地设成隐形。
│  └─ 全程盲操／仅听音 [已实现]
│     隐藏当前块或全部关键画面，分别需要显示开关和足够的声音提示；当前无法仅靠配置完成。

├─ 8. 指定消除与连击
│  ├─ 连续 TSD [已实现]
│  │  ├─ 基础：累计完成 20 次 TSD，其他消行不允许；不消行落块允许 [已实现]。
│  │  │  用 40 行结束目标和“所有消行都是 T 块非 Mini Spin Double”结算检查即可表达。
│  │  ├─ 困难：基础条件上，不允许连续 4 次 TSD 使用同一旋转中心列 [已实现]。
│  │  └─ 极限：新的 TSD 中心列不能与最近 4 次重复 [已实现]。
│  │     “20 次通关”是本项目拟定的有限目标；也可后续另设无尽计数，二者不共用成绩。
│  │     简单版不用为恢复原版无限计数而增加专用结束机制；列限制版需额外位置历史。
│  ├─ 纯消四 [已实现]
│  │  ├─ 普通：完成 40 次四消，不允许其它消行，允许不消行落块 [已实现]。
│  │  │  可以用 160 行目标与结算消行表验证；不要求复刻原版 100 次评级。
│  │  └─ 极限：在纯消四基础上限制落点重复，例如相邻四消不能用同一列 [已实现]。
│  │     重点是迫使玩家改变堆叠位置；不必照搬原版最近 8 列历史，但最终窗口大小需固定。
│  ├─ 单消马拉松 [已实现]
│  │  200 行，只允许单消、不允许 Spin、不允许连续两块都消行；允许插入不消行落块断连。
│  │  使用现有消行统计和 maxCombo 验证，按本项目马拉松曲线运行；不强求原版 HPC 分支。
│  └─ C4W 四列连击练习 [已实现]
│     ├─ 普通：实际场宽 4、目标 100 行，允许断连，记录用时与最大连击 [已实现]。
│     ├─ 困难：同样的窄场地，提高重力或缩短锁延，仍允许断连 [已实现]。
│     └─ 疯狂：初始建形阶段后，每次落块都必须消行，以连续消行长度为主要成绩 [已实现]。
│        初始建形可选少量固定初始方块/短宽限期，需先验证存在合法起手。
│        不要求原版侧墙与 3/6 格随机初始形；保留窄井空间紧张、维持长连击的核心。
│        非严格版可以按正常终局成绩计分；严格版需记录建形结束点和之后是否断连。

├─ 9. 全清
│  ├─ 100 行内尽量全清 [已实现]
│  │  ├─ 普通：低重力、宽松锁延，可允许无限 Hold，主要考察全清规划。
│  │  ├─ 困难：常规 Hold 与正常重力，减少思考余量。
│  │  └─ 疯狂：更高重力或更短锁延，要求快速识别全清机会。
│  │     用本项目全清定义和 allClearCount；同一行数目标下比全清次数，不移植 O-Spin 条件。
│  ├─ 连续全清 [已实现]
│  │  ├─ 普通：每个全清周期允许的累计消行数与当前堆高之和不超过一个固定预算。
│  │  └─ 困难：收紧预算/思考时间，可禁止 Hold。
│  │     初始候选预算为 4 行；每次全清重置，限制过程高度而非只看终局是否全清。
│  │     无需复制原版每 5 次全清减一帧重力，但必须有“一个周期失败就结束/停止该项计数”的约束。
│  └─ 全清训练题 [已实现]
│     ├─ 固定单题：使用现有地图与固定块序，目标为全清；比较成功及落块数/用时 [已实现]。
│     │  以地图内容、块序与规则的指纹绑定成绩，不能只依赖会被编辑的地图编号。
│     └─ 连续题库：解完一题继续下一题，按题量和难度升级 [已实现]。
│        可以从少量本项目题目起步，不要求导入 Techmino 全部题库或其镜像抽题算法。
│
├─ 10. 构造与图形
│  ├─ 对称 40 行 [已实现]
│  │  第一版定义为“每次消行完成后，左右镜像位置若都有方块，则块型应按指定镜像关系配对”。
│  │  允许单侧暂时未填满，保留可逐步构造的玩法；使用块型而非用户自定义显示颜色判断。
│  │  核心是同时顾及两侧形状与消行，而不是机械移植原版颜色表。
│  ├─ 秘密段位：大于号堆叠 [已实现]
│  │  按逐层单孔与封口形状计算最高完成层数，同层数块数少者优先。
│  │  用适合本项目出生点与场高的等级上限；不强求原版段位名称、镜像快捷键或 23 层门槛。
│  └─ 棋盘格/指定轮廓堆叠 [已实现]
│     先支持一种固定图案与按完成层数计分，再考虑通用模板系统；不以先做完整拼图编辑器为前提。
│
├─ 11. 机器人挑战（已接入单窗口对战与人类成绩归属）
│  ├─ 单挑 Bot [已有]
│  │  使用 bot_chatgpt；简单 0.7、普通 1.2、困难 1.5、疯狂 2、极限 2.5 PPS，固定搜索宽度 300。
│  │  不要求原版三条命，难度重点保留在对手强度；只有人类方成绩计入挑战。
│  └─ 回合制 Bot [已更新]
│     复用小数单轮落块数：玩家每轮 1 块，Bot 每轮 0.3／0.5／0.75／1／1.2 块，Bot 预设 2 PPS。
│     胜利优先并比较更短用时，失败也记录并比较更长生存时间；不使用命数设置。
│
└─ 12. 扩展机制（现已接入）
   ├─ 干旱 100 行 [已实现]
   │  核心是无 I 块；可新增六块集合的袋随机，不必严格复刻原版 12-Bag。
   │  随机挑一组固定长序列只能当题目，不能等价当作无尽的无 I 随机器。
   ├─ 干旱+ 100 行 [已实现]
   │  核心是根据当前地形给不利方块；可先实现本项目简化的候选评分，不照搬原版全部权重。
   ├─ 极简操作竞速／科研 [已实现]
   │  需要与本项目旋转系统相匹配的逐块操作计数和最简操作标准；ARR=0 本身不能代表极简。
   ├─ 阶段任务大师 [已实现]
   │  可用“20G+几个明确任务+逐阶段加压”保留虚幻类思路，不要求完整原版剧情/多命/骨块。
   │  仍需任务状态与阶段切换；当前没有该管理机制。
   ├─ 堆积 Stack [已实现]
   │  核心是延迟消行、累积多行后一起结算；涉及现有消行与顶出流程，不能只换结束目标。
   └─ 49／99 人机器人混战、仅听音完全盲操 [已实现]
      前者需要大量 Bot、目标选择与排名结算；后者需要声音提示体系。
      可以不复制徽章和原版规则，但这些核心基础仍需建设。

原设计实施备注（当前实现已见上方两份说明）
├─ “可加入”也可能需要新的成绩类型，例如分数、最少块数、APL 或无尽总量；这不是新落块机制。
├─ 现有挑战统一 val 会拒绝隐形、其它方块集、地图、无限 Hold 等情况；需改成按挑战分别核验。
│  允许差异仅限该项规则，不是把所有检查放开；比赛计时、实际运行配置和规则倍率仍须一致。
├─ 默认保持当前“同一局结束后评估多个挑战”的方式，不因某一候选条件失效而打断自由游玩。
│  基础 TSD/纯消四/单消可做整局结算验证；列历史、周期预算等则需逐块记录状态。
│  若以后做专用挑战入口，再选择是否在违规时立即判负、保留此前有效成绩和结束时刻。
├─ 人类单机、正常游戏时钟、不用暂停/撤销继续作为共同基线；个人外观和语言不影响成绩。
│  Bot 对战是明确例外，仅放开人类挑战 Bot 所需的对战环境，不把 Bot 自己的成绩计入。
├─ 完成目标后再比较用时/分数/块数；未完成局先比较进度，避免短局低块数或高效率反而压过完成局。
│  “40 行效率”正式榜建议只收达标局；无尽类按该项有效总量评价，不给生存时长无限堆分。
├─ C4W 要说明“连续消行次数”与 UI Combo 的首消偏移；不能直接把两种显示数字当成同一数值。
├─ 已有挑战如果保持规则则保留 ID 和 PB；以后确实改变计分或压力规则时才另立 ID/版本。
└─ 优先顺序：竞速缺项、攻击/效率、挖掘效率、半隐/全隐、Backfire、马拉松/20G、小场地，
   然后补列限制、连续全清、C4W 严格版和图形评分；新随机器/任务/机器人入口放在后面。
