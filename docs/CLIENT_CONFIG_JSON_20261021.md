# 统一客户端配置（2026-10-21）

正常启动的终端版和 OpenGL 版共用 `.tetr/config.json`。JSON 版本为 1，包含：

- `players.player1`、`players.player2`：分别按 `linux`、`windows` 保存原平台设置和多重键位，导入的旧通用配置保存在 `legacy` 中。
- 每个玩家配置的 `settings` 按原设置分组保存整数、浮点数、字符串及键位数组；`presets` 保留原有恢复编码，`quick_play_recovery` 保留 Quick Play 恢复值。
- `graphics`：窗口尺寸、最大化、垂直同步和帧率上限。
- `active_player`：单人游玩时使用的玩家。

两端正常保存均写入该文件；键位修改不再另写默认的 `keybinding*.txt`。
已有 INI、旧键位文件及显式配置导入接口继续可读，显式自定义 INI 保存接口仍供兼容工具使用。
两端的 `--migrate-config` 可不进入游戏、不开窗口地执行导入；自动迁移不会删除旧文件。
坏 JSON 或不支持的版本会拒绝覆盖。对同一文件的修改在跨进程文件锁内读、合并并原子替换，
保存某个玩家或窗口参数不会覆盖另一玩家的数据。JSON 数值直接按原类型读取，避免反复经过旧文本数值解析。

挑战历史仍使用原有格式，改名为 `player1_linux.challenges`、`player2_linux.challenges`
（Windows 使用对应平台后缀）；启动时将旧 `*.ini.challenges` 复制到新位置，原文件保留。
地图和预设库、录像及最近录像格式保持原状。删除地图时同步更新 JSON 中的所有平台和玩家引用。
玩家的联机录像身份仍按原配置身份计算，合并文件不会让两名玩家共享身份或改变既有回放主视角识别。

全键盘设置、地图和回放操作继续使用共享控制器。回放路径旁的一个“打开”按钮调用系统文件选择器，
默认 `./.tetr/replay`，F4 提供键盘入口；地图及预设重命名不带文件按钮。候选方块单击一次加入一个，
设置滚轮只移动鼠标所在列表的视口，键盘选中项保持不变。

本次清理仅在对当前目录建立完整外部备份并核对迁移结果后执行；地图、预设、录像和挑战成绩保留。
具体清理清单、备份位置及验证结果记录在本机 `runlogs/config_json_20261021.json`，个人数据不进入源码或发行包。
原生 Windows 的系统对话框、输入法和显卡体验仍待实机验收，不以 Linux 自动化替代。
