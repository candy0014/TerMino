# OpenGL 双前端预览

`tetr_gl` 已接入原应用的完整设置、地图与预设编辑器、挑战目录、Bot、本地双人、网络房间、观战和统计流程。首页、设置、选项、输入、改键、地图编辑、统计与房间等待均使用独立的图形布局，消费共享应用的语义模型；棋盘使用 OpenGL 原生绘制。局内统计与事件集中在棋盘左侧，右侧保留 NEXT，底部使用实际绑定生成的按键块。图形渲染器不再绘制终端字符画布。规则、参数校验、保存和协议继续使用原实现。终端程序及全部工具保持独立构建。当前仍为迁移预览，原生平台全功能与全键盘实机验收待完成，本轮不发行。新版视觉、实现边界和截图验证见 [图形视觉改造](GRAPHICAL_REDESIGN.md)；固定棋盘、TETR.IO 风格信息层级、推进器、联机布局和统计表的修订见 [布局对照](GRAPHICAL_LAYOUT.md)。

## 分别构建

Linux：

```sh
./compile.sh --frontend terminal
./compile.sh --frontend opengl --test
./compile.sh --frontend both --test
```

Windows（CMake、Visual Studio 2022 C++ 或 MinGW）：

```powershell
./compile.ps1 -Frontend terminal
./compile.ps1 -Frontend opengl -Test
./compile.ps1 -Frontend both -Test
./compile.ps1 -Frontend opengl -Generator 'MinGW Makefiles'
```

日常编译脚本的三种前端选择统一使用 `build/`。Linux 运行 `./build/tetr` 或
`./build/tetr_gl`，字体资源也随图形程序放在 `build/resources/fonts`。不带参数默认同时构建
完整终端版和图形版，等价于 `./compile.sh --frontend both`；显式选择 `terminal` 时不要求图形依赖。
PowerShell 默认也使用 `build`，Visual Studio 的可执行文件位于 `build/Release` 等配置
子目录；显式 `-BuildDirectory` 继续有效。已有其他构建目录及其中的数据不会自动删除。

用于隔离检查、CI 和打包的 CMake 预设继续使用 `build-<预设名>`。例如 `terminal-linux`、
`opengl-linux`、`both-linux`，Windows 对应 `*-windows` / `*-windows-mingw` 预设：

```sh
cmake --preset opengl-linux
cmake --build --preset opengl-linux
ctest --preset opengl-linux
./build-opengl-linux/tetr_gl
```

图形目标是 `tetr_gl`；终端目标仍是 `tetr`、`tetr_ft7`，服务端是 `tetr_server`。纯图形配置不生成终端程序；纯终端配置不查找 SDL、OpenGL 或字体依赖。无窗口与无终端输入的契约检查使用 `frontend-headless-linux` / `frontend-headless-windows`。

图形构建优先使用系统 SDL3 ≥ 3.2、FreeType；缺少时下载有 SHA256 校验的 SDL 3.4.18、FreeType 2.14.1 并静态编译。`-DTETR_GRAPHICS_FETCH_DEPS=OFF` 禁止下载。Linux 构建 SDL 需要相应 X11 或 Wayland/xkbcommon 开发包，运行需要 OpenGL 3.3 Core 驱动。依赖清单见 `cmake/OpenGLFrontend.cmake`。中文字体 Noto Sans CJK SC 随程序安装，来源、版本和许可证见 [字体说明](../resources/fonts/README.md)。

## 完整键盘路径

| 流程 | 操作 |
| --- | --- |
| 启动 | 方向键、Tab / Shift+Tab 移动焦点，Enter 开始/设置/退出；原 R 开始、P 设置、Esc 退出仍可用 |
| 完整设置 | P 打开；↑/↓、PageUp/PageDown 选择，Enter/→ 进入或编辑，←/Backspace 返回，Esc 返回启动页，R 开始/重试；沿用原确认两次和恢复默认规则 |
| 设置内容 | 原全部设置与条件显示、13 类控制绑定、全部模式和目标、旋转/随机系统、模拟、回合制、全部 Bot、外观与语言 |
| 文本与路径 | SDL 文本输入与输入法组合串；←/→、Home/End、Backspace/Delete、Ctrl+A、Ctrl+V、Enter、Esc；中文姓名和路径使用 UTF-8 |
| 改键 | CONTROLS 中选动作，按下并释放要增加/移除的键；保留多重绑定及 Esc 优先规则 |
| 地图 | Maps → 新建/选中地图 → 编辑；保留原数字绘制、方向、Tab 切换版面/序列、搜索、撤销/重做、P 选项、S 保存及退出确认 |
| 预设 | Presets → 新建/编辑；保留定义/未定义参数、命名、保存、应用、层叠、撤销和删除 |
| 挑战 | Challenges → 原目录、挑战说明、开始/调整、成绩、资格和录像入口；使用同一 136 项固定挑战注册目录 |
| 网络 | 重开键从首页按当前模式开局；联机模式未入房时直接创建/加入房间，已入房时进入对战准备。设置键仍单独打开设置；NETWORK 保留地址、身份、房主管理、规则和容量等原操作 |
| 对局 | 默认 ←/→ 移动，↓ 软降，Space 硬降，↑ 顺时针，Z 逆时针，A 180°，C Hold，U 撤销，F2 暂停，R 重试，P 设置；全部以当前玩家绑定为准 |
| 双人和观战 | 保留双方独立绑定、共享物理事件历史；原焦点切换、房间等待、观战及统计页操作继续生效 |
| 回放和结果 | MODEL 选择 Replay 并输入路径或选最近回放；原暂停、速度、定位、重放键有效；完成后 Tab 统计、方向键/翻页，S 输入文件名保存 |

鼠标不是任何操作的前提。首页、设置菜单与选项列表支持点击，滚轮等价于上下选择，返回按钮等价于左键；原控制器继续负责确认、验证和保存。改键与文字编辑保留完整键盘路径。后续新增设置、挑战和编辑器操作继续同时进入两端。

SDL 物理键转换到当前平台原键码，不读取 evdev 或全局键盘，也不创建终端原始输入会话。兼容字母、数字、导航、功能、左右修饰、小键盘、国际及媒体键；Linux 扩展映射来自固定 SDL 源码，Windows 兼容旧档案的通用 Shift/Ctrl/Alt。特殊硬件事件仍受操作系统和 SDL 能否投递限制，第四阶段需实机验证。失焦抑制按住状态，恢复后释放再按；文本事件与游戏动作分离。

## 档案与参数

默认读取并维护当前运行目录下原平台的玩家档案、键位、地图、预设、挑战历史和回放，两端使用相同格式。`--data-dir DIR` 切换到独立运行目录，其 `.tetr` 保存该次运行的数据；测试必须指定临时目录。命令行文件参数在切换目录前解析。

```sh
./build/tetr_gl --data-dir /tmp/termino-gl --play
./build/tetr_gl --data-dir /tmp/termino-gl --replay /absolute/demo.txt
./build/tetr_gl --data-dir /tmp/termino-gl --profile /absolute/player1_linux.ini
```

`--profile FILE` / `--profile2 FILE` 导入双方档案，导入的 INI 不自动写回；编辑地图、预设、历史和录像仍使用运行目录。可以传入原终端的 0–2 个位置键位文件参数、`--play`、`--qp-continuous-cancel`；仍支持 `TETR_USER_CONFIG` 和 `TETR_USER_CONFIG_PLAYER2`。`tetr_ft7` 等离线工具保留独立可执行入口。完整参数通过 `--help` 查看。

回放保存沿用共享对话控制器、文件编码、校验和历史登记；图形版显示独立输入对话框，终端保留原布局。裸文件名位于 `.tetr/replay`，`./` / `../` 相对运行目录，绝对路径按原规则处理，文件扩展名由输入决定。图形版不再使用第二阶段固定 `gl-*` 命名的简化保存入口。

棋盘支持原尺寸、隐藏行、Hold/Next/Ghost、出生提示、方块样式、垃圾、目标、Quick Play 状态、消除信息和多棋盘场景。场地抖动、粒子、落块冲击、消行光效和硬降光轨由图形渲染单独处理，默认强度以棋盘可读为优先。规则在独立会话线程运行；`--no-vsync`、窗口大小及绘制频率不推进规则。

## 场地特效设置

在图形版进入 **设置 → 外观 → 特效**，用方向键选择项目、Enter 编辑数值并确认；← 或 Backspace 返回上一级，Esc 返回开始界面。
以下七项集中在特效子菜单，仅在图形版显示；终端版隐藏整个特效入口，共用配置文件仍会保留其数值。
特效子菜单的“重置”仅恢复这七项；外观菜单的“重置”仍恢复全部外观参数，均需再次确认。
以下各项均可设为 **0～200%**；0 关闭，100 为标准量，200 为增强量。
总强度与各分项相乘。修改立即生效并保存；同一客户端的双方共用，联网房主规则不会覆盖个人特效。

| 项目 | 默认值 | 内容 |
| --- | --- | --- |
| 特效总强度 | 100% | 统一缩放全部场地特效；0 一次关闭全部 |
| 版面弹性 | 100% | 撞墙侧推、Spin 倾斜、落块和消行冲量带动整个版面；强度越高，位移和回正时间越大 |
| 场地抖动 | 35% | 垃圾受击与强消行的短促震动，与版面弹性独立 |
| 粒子强度 | 35% | 拖曳火花、旋转碎片、余烬的数量与叠加柔光 |
| 落块冲击 | 5% | 锁定高光、柔光冲击环及地面扩散 |
| 消行光效 | 5% | 消除行闪光、横向光波、边缘耀光与特殊消行的框体脉冲 |
| 硬降拖尾 | 5% | 彩色光柱、白色内核及细长速度线 |

暂停会冻结效果，重开、撤销和回放跳转会清理旧效果；回放使用观看者的外观偏好。
隐形场地与盲打／音频／直觉挑战屏蔽可能暴露方块位置的光轨、粒子和空间闪光。
版面弹性会带动棋盘、边框、Hold/Next、用户名和两侧统计一同移动；页头与底部键位保持稳定。
设版面弹性为 0 可关闭弹性位移，场地抖动仍由自己的分项控制；总强度为 0 则全部关闭。
粒子使用独立随机数，不消耗游戏块序或垃圾随机数。

## 验证与边界

`frontend_ui` 验证值画布、嵌套/线程隔离、UTF-8 光标编辑和确认取消；`graphical_application` 在临时目录通过实际键盘驱动共享设置、地图、预设、改键、挑战、Bot、结果、保存、双人及混合客户端房间流程。`graphical_session` 保留录像与原 App 入口的语义一致性检查，`sdl_input` 验证键位、时间戳、重复过滤和焦点恢复。这些测试都不创建窗口。

实际 OpenGL 检查必须隐藏或离屏运行：

```sh
SDL_VIDEO_DRIVER=offscreen ./build/tetr_gl \
  --data-dir /tmp/termino-gl-smoke --smoke-test --screenshot /tmp/termino-gl-smoke.bmp
```

`--smoke-test` 和 `--frames N` 自动从创建时隐藏窗口，`--smoke-test` 强制指定独立数据目录；也可显式传入 `--hidden`。正常启动显示窗口。禁止让自动化测试窗口出现在用户桌面。

仍保留过渡性终端呈现适配库以运行原共享应用；图形会话关闭 ANSI 输出，以值画布承载复杂界面，没有解析终端转义序列或复制游戏规则。应用控制器仍有阻塞循环；后续可逐项改为可推进调度器，不能以重构为由缩减内容。原生 Windows 输入法、DPI、真实显卡和 Linux 桌面设备体验的完整验收属于第四阶段，Wine 不代表原生 Windows 验收通过。

`cmake --install <build-dir> --prefix <empty-dir> --component OpenGLPreview` 安装图形程序、字体、说明和许可证，不复制个人 `.tetr`。四组合独立候选包改用 `tools/package_frontends.py` 和 `ClientTerminal` / `ClientOpenGL` 组件；说明见 [验收与打包](FRONTEND_ACCEPTANCE.md)。远程 CI 本轮未触发，正式发行等待实机验收与明确发行指令。

## 窗口配置与运行目录

`.tetr/config.json` 的 `graphics` 保存窗口尺寸、最大化、垂直同步和显示帧率上限。可用
`--window-size 1280x800 --frame-limit 240 --no-vsync` 覆盖，默认显示上限为 240 Hz，
不改变规则时钟。输入法组合期间，方向、删除、确认和取消按键交由输入法处理。

窗口不设置应用层最小尺寸，缩小时界面继续等比缩放；命令行和保存的窗口配置也接受小尺寸，
例如 `--window-size 600x400`。宽高须为正数，上限维持 16384；配置中的非正尺寸恢复默认值。

可重复启动图形程序，在同一台电脑、同一运行目录打开多个独立窗口。各窗口启动时读取
已保存配置，随后可独立调整设置与键位；首个窗口保存玩家配置、键位、活动玩家和窗口设置，
后开的窗口使用临时配置，标题注明“临时设置”，关闭时不会覆盖原配置。成绩、挑战历史、
地图、预设和录像共用，保存时短暂加锁；各窗口的游戏与输入状态独立。

图形客户端共享 `.tetr/client.lock`，终端客户端继续获取排他锁，避免旧终端写入与图形多开
发生冲突。首个窗口退出（包括异常退出）后，后续新开的窗口可成为设置保存窗口；已经打开的
临时窗口保持临时状态。锁由操作系统释放，无需删除锁文件。需要完全独立的数据时仍可使用
`--data-dir DIR`；旧配置、成绩和回放格式不变。

### 点按误触自动重复修复（2026-10-18）

DAS 90 ms、ARR 4 ms 下，短于 DAS 的点按曾因 SDL 松键事件等待下一次图形轮询而实际多移格：
共享引擎已按墙钟执行重复，随后收到较早的松键时间戳也无法撤销这些移动。隐藏窗口的
120 Hz 受控复现中，72 次短按有 31 次多移格；240 Hz 为 19/72。

SDL 事件循环现在在收齐每批事件后公布采集截止时刻。通用输入缓冲区原子地提供这批事件、
已确认的按键状态和截止时刻；共享输入处理、DAS 预充能及出生预移动只使用已完整采集的
输入时间，批次推进也会唤醒等待中的引擎。终端的异步输入源继续使用原有墙钟路径。
没有增加另一套移动规则，也没有修改 DAS、ARR、垂直同步、游戏时钟或录像／网络格式。
SDL 和 OpenGL 仍由主线程处理。

新增 1,080 组确定性回归覆盖左右键、30–1000 Hz 采集节奏、DAS 两侧的点按和长按、
ARR 0/4/10 ms；另覆盖未完成批次、独立玩家读取、无事件批次唤醒和出生预充能。
原有输入处理实现会触发新增回归断言，修复后通过。
实时隐藏窗口对照的 384 次按压最终位移全部符合实际按压时间，其中 212 次图形端
短于 DAS 的按压均只移动一格。测试记录与可单独反向应用的补丁位于
`build-migration-backups/input-capture-fix-20261018/`，不生成截图。

以上结果来自注入输入和 Linux offscreen 绘制，不替代实体键盘、桌面合成器及显示器延迟验收；
Windows 的原生设备与显卡体验继续保持 pending。本轮使用隔离运行数据，保留原有 `.tetr`。

Linux 图形 12/12 与隐藏窗口冒烟通过。终端全量首轮 157/159 通过；新增预充能测试适配
CTest 的 20 倍测试时钟后通过，自动落子绘制时序项单独复测通过，159 项最终均通过。
Windows MinGW 构建终端、FT7、服务端及图形程序成功，Wine 的 5 项相关输入／预充能回归

## 长局落块停顿修复（2026-10-18）
