# ChatGPT BOT：按机制优化 Mod 与组合（2026-10-21）

本轮从 Allspin / 逆位 Allspin 扩展到所有 QP Mod、逆位及组合。通用机制根据实际能力和状态判断，只有 QP 独有结算读取相应规则；不根据测试种子、对手或场景名称选策略。实现位于共享 BOT 层，终端与 OpenGL 同时使用。

## 搜索与评分

| 实际机制 | 调整 |
| --- | --- |
| 暂存、预览与随机出块 | 按真实 HOLD 能力、可见 NEXT/HOLD 调整块型储备和窄井依赖。均匀随机且不能 HOLD 时，在预算内完整遍历所有允许的未知块，再比较其期望与较差结果；未知块不能当成可选的有利分支。 |
| 重力、横移、旋转与下降限制 | 枚举真实可用命令，保留 20G、零 DAS、禁用操作的路径语义；受限移动提高新埋洞代价。窄井的填充块必须存在可用的朝向。 |
| 垃圾、双洞与混乱场地 | 按可玩高度、堆高和已知垃圾压力确定挖掘紧迫度；增加覆盖当前垃圾出口的代价。不会仅因六行垃圾存在就一律切成挖掘策略。攻击与 B2B 的基础权重保持不变。 |
| 攻击、抵消和自返垃圾 | 使用真实结算的攻击资格、抵消、发送和缓冲区变化；自返垃圾作为费用，区分抵消前后的自返顺序。无法抵消的攻击不会产生抵消信用。 |
| 全旋与 Mini 能力 | 按实际 Spin 能力调整 T/I 储备。为可见块的可执行后续 Spin 保留搭建；机会值只属于叶节点评价，不累计成攻击。 |
| 场地大小和块型 | 以真实可玩底部计算地形；风险按可用高度缩放，避免把四行场地的一行压力当成二十行场地的一行压力。新增不可玩行扣除空间费用，大块增加空间储备代价。雪球扩展、计时底部衰减和特殊块仍由共享规则结算。 |
| QP 独有规则 | 按真实重复类别保留 Allspin 的继续路线，rAS 即死候选不能被高攻击补偿；保留 BLIGHTED 攻击资格及真实补行、经验、推进器、历史和组合优先级。 |

十列标准 SRS+、普通可操作条件的规则搜索复用原生预计算几何图。它保留同一占用格对应的普通、Mini、完整 Spin 分支，避免 rAS 中只保留“最强 Spin”而删掉必要的重复类别切换。其他场宽、特殊块、20G、整段横移和禁用操作使用完整移动模型。纯几何加速不代替落块、攻击或 QP 结算。

通用枚举对空中无障碍区作保守压缩，每个姿态只展开一次，但仍检查不同进入旋转的落点类别；对称方块按实际占用格去重。原生枚举也修正了压缩下降后丢失侧面高台路线的问题。不可变块型定义被缓存，避免每个候选复制形状和踢墙表。

默认宽度 300 保持原生 100 ms、规则搜索 90 ms 的预算，另有公共验证开销。规则搜索最多七层可见块，有限束宽保留不同 HOLD / 队列消耗、B2B、攻击资格和重复类别。更深并不一定更强：单纯缩窄束宽，以及一律增加挖掘奖励的试验产生回退，未作为最终方案。

## 验证方法

固定相同公开设置与随机种子，通过真实共享 Engine 执行出块、HOLD、路径验证、落块、垃圾、场地变化与时间推进。周期计入 `max(100 ms, 实测搜索及验证耗时)` 和真实消行/进块等待，上限约 10 PPS。数据全部位于内存或隔离临时目录，不读取、修改个人 `.tetr`。

单项：基础配置及全部 27 个 Mod 变体；组合：26 组覆盖全部 Mod 家族的代表性组合。种子 123、456、789，每局 10 秒；前后版本冻结，顺序交替，每对在同一工作线程/CPU 核心运行。最终共 162 对、324 局。组合不是穷举。死亡局保留原始结果。此前的 15 秒分批试验只作调参记录，不混入最终成对统计。

新增统计记录 Spin 消行、零行 Spin、普通消行、Quad、Allspin 惩罚行，以及标准七族的 Spin 行数分布。分布最后一栏是 4+；其他特殊块仍计入总 Spin 数。新增统计器最初对非七族的下标越界已修复；最终全部修改前成绩统一由原始未加统计程序生成，不把早期统计器错误记成 BOT 死亡或 0 分。
