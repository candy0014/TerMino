# Tetris 现代俄罗斯方块

玩法大致参考 [TETR.IO](https://tetr.io/) 的第二赛季规则。

- 模式：无 / 竞速 / Blitz / QP2（仿）/ 双人联机对战
- 随机生成器：X-Bag / Random / 2026 TETR.IO QP 愚人节
- 块/旋转系统：四连块(SRS+/SRS/ARS) / M123 / 五连块 / 六连块 / 2026 TETR.IO QP 愚人节
- 控制：支持修改键位 / 重力 / SDF / DAS / ARR
- 游玩：支持修改宽高 / 移动重置时间及次数 / Next个数 / 是否开启Hold / 全隐 / 反重力 / 各种垃圾行模式
- BOT：目前为 while_1 编写的 beam-search bot，S2 规则下平均 $1 \text{APP}$。

## 运行方法

请确保你的电脑上有 g++ 编译器，且其版本支持 c++17，并且能在终端中运行他。

运行游戏前，可打开 `user_config.txt` 修改默认配置。

该文件内部几乎所有配置都可在运行后修改，但重新运行后将会重置为该文件里的配置（除键位）。建议在此修改 DAS 等不常用配置。

注意 `Server IP` 和 `Linux Keyevent` 必须在运行前修改。

Linux 下若不会修改 `Linux Keyevent` 可重新运行 `compile.sh` 并按其提示修改。

### Linux

```bash
bash compile.sh
# 编译完成后将会提示修改 Linux Keyevent

sudo ./server
# 不联机则无需运行

sudo ./tetr
```

### Windows

双击运行 `compile.bat`。

运行 `server.exe`（不联机则无需运行）。

运行 `tetr.exe`。

## 游玩方法

直接运行即可进入游戏。

默认键位：
- 左移：方向左键
- 右移：方向右键
- 顺时针转：方向上键
- 逆时针转：Z
- 180 度旋转：A
- 软降：方向下键
- 硬降：空格
- 暂存：C
- 重开：R
- 修改配置：P
- 保存回放：U

修改配置说明：在任意时刻按“修改配置”键进入修改配置界面，上下键选择项目，左右键切换界面，回车键选中修改，输入值后回车表示输入完成，按“重开”键重新进入游戏（版面将被清空）。

## 可能的问题

**请先查看自己的操作是否符合【运行方法】中的内容。**

- 方块显示不清楚（有黑色的竖线）：
	
	1. 尝试修改 `Square Version` 配置；
	
	2. 运行游戏，右键点击运行窗口上方；
	
	3. 点击【属性-->字体】，将字体改为黑体。
	
- 显示错位：在某些电脑上，调整窗口大小的代码可能不能起效，需手动调节窗口大小。

- 联机失败：一台电脑仅能开一个服务器，服务器需在客户端运行前运行，且仅支持前两个客户端接入，不允许某个客户端退出后再次接入。
