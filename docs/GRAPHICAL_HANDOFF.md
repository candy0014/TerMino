## DAS 调查结论与证据边界（早期记录）

以下保留早期探针结果。后续时序修复见 [计时记录](DAS_TIMING_FIX_20261020.md)；临时 `--live` 探针和重复帧率轨迹已在测试整理时移除，当前回归入口见 [输入线程记录](GRAPHICAL_INPUT_THREAD_20261020.md)。

没有复现图形版缩短 DAS。两端共用 `MovementInputState` / `process_buffered_player_input_frame`，按单调时间计算，不以渲染帧计数。
Linux evdev 使用 CLOCK_MONOTONIC 事件时间，SDL 通过 `EventClock` 换算到 steady_clock；图形帧率不会乘到 DAS 上。
新增 `frontend_handling_test` 对照 evdev 格式时间戳和真实 SDL 输入适配：

- DAS 50/100/200 ms、ARR 0/10/20 ms：阈值前 1 微秒不重复；验证排队按下/释放和系统自动重复。
- 30/60/120/144/240/1000 Hz 采样：两路位置始终一致，同一 365 ms 按住轨迹最终都移动 28 格。
- `--live` 使用真实 live-piece 游戏循环、终端绘制路径与 detached/SDL 路径，捕获录像中的实际移动时间。
  DAS 100 ms 时测得首次重复分别为 100.143 ms、100.381 ms；50/200 ms 也未提前。
- `--live` 的终端 ANSI 输出捕获到内存，输入为注入的时间戳；没有操作实际键盘或测量桌面合成器/显示器的按键到像素延迟。
  因此可以排除已测路径中的 DAS 算法缩短，显示反馈差异是合理解释，但不能声称已定量证明用户实机的全部差异。
- 本轮没有为了匹配主观手感改变 DAS、ARR、预充能或加人为延迟。
