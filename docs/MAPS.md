# 地图与编辑器

根菜单「地图」依次列出「新建地图」、「不使用地图」和已保存的地图。每张地图的子菜单包含「使用地图 / 编辑地图 / 删除地图」。选择地图名称直接进入子菜单；新建、使用、编辑、删除和停用地图仍要先请求确认，再按一次新的 Enter 才执行；长按 Enter 不会确认，方向键取消确认。地图名称可以重复，地图列表以 `#编号: 地图名称` 显示，例如 `#1: Pumpkin`；场地大小、出块方式及最终目标放在提示栏。

选图时，右侧预览按正常格子大小完整绘制，不包含 HOLD、NEXT。只有整个场地连同边框能放入右侧，并能给提示与操作信息保留足够高度时才显示；否则隐藏预览。终端缩放后会重新判断，地图参数仍显示在提示栏。

「使用地图」保存当前玩家的选择，单窗口对战中也可为双方分别选择，或在修改对象为「双方」时同时选择。地图优先提供场地尺寸、初始格子和出块方案；普通场地设置保留供取消地图后使用。地图关闭 Fool/Snowball 的额外出块及初始场地修改，以保持所编场地和块序。其他对局规则继续生效。预设保留地图选择。

## 编辑操作

编辑器分为「版面编辑」和「块序编辑」两个界面，Tab 切换。大场地随光标滚动，终端缩放时重新布局。标题中的 `*` 表示尚未保存的修改。退出选择框与设置选择框一样靠上排列。版面上方用圆圈数字显示颜色：⓪ 空没有色块背景，①～⑧ 的背景就是对应颜色；当前方格用菱形与高亮背景标记。

| 按键 | 操作 |
| --- | --- |
| Tab | 切换版面 / 块序编辑界面 |
| 方向键 | 版面中移动方格；块序中四方向按网格选候选块；支持长按 |
| Shift＋左右 | 调整块序插入位置，松开 Shift 立即恢复选块 |
| 0～8 | 直接涂色：0 空、1 垃圾灰、2 I、3 J、4 L、5 O、6 S、7 T、8 Z；按住数字移动可连续涂色，按住 0 可连续擦除 |
| Enter | 版面中使用当前颜色；块序中插入当前候选块，留在原界面继续操作 |
| P | 打开 / 收起编辑设置：保存、重命名、宽度、高度、出块方式、地图模式和退出；固定出块方式下面显示旋转系统，愚人节2026下面再显示初始楼层，自定义块序显示方块库选择 |
| 设置内方向键 / Enter | 上下选择；右 / Enter 打开宽度、高度输入或旋转系统列表，其他选项用左右调整；Enter 执行操作 |
| S | 立即保存当前地图，不询问名称或确认；版面、块序、设置与旋转系统选择界面均可使用 |
| Delete / Backspace | 删除光标后的块 / 光标前的块 |
| Esc / 设置里的退出编辑 | 没有未保存修改时直接退出；有修改时以橙色询问，方向键选择「保存退出 / 不保存退出 / 不退出」，Enter 执行，Esc 返回编辑 |

以上操作不需要功能键。可选快捷键仍支持：PgUp / PgDn 候选块翻页，`/` 跨系统检索，Home / End 定位块序首尾，Ctrl+Z / Y 撤销 / 重做，I/J/L/O/T/Z 快速插入；S 固定用于保存，可通过方向键选择 S 块并按 Enter 插入。F2/F5 可分别输入宽度 / 高度，旧的 F3/F4/F6/F8 出块方式、旋转、楼层和撤销保存快捷键仍兼容。

第一次按 S 保存新地图时，自动使用最小的尚未占用名称「地图i」，i 为正整数。例如已有「地图1」「地图3」时，默认名称为「地图2」。在编辑设置中打开「重命名」输入字符串，可包含字母 S、中文或已有名称；按 Enter 修改草稿名称，随后按 S 保存。使用任意已有名称也可保存，不会按名称覆盖其他地图。编辑已有地图保存时，只更新该编号。

重命名输入时 Esc 取消修改，留空保留原名。保存操作不进入名称输入界面。保存后仍可继续编辑；使用兼容快捷键 F8 可撤销最近一次文件保存：新地图移除刚创建的记录，已有地图恢复保存前内容。若该记录已被其他操作修改，撤销不会覆盖那些修改。选择「不保存退出」不会写入当前草稿，已经保存的版本仍保留；从未保存的新地图不会创建记录。选择「保存退出」会保存当前草稿并退出；保存失败时保留草稿和询问界面。选择「不退出」返回原来的版面、块序或设置界面。

地图编辑固定使用 S 保存，与游戏的「保存回放」绑定无关。文字或数值输入期间键盘用于输入，确认 / 取消后即可继续按 S 保存。

## 块序候选区与出块方案

块序界面左侧较窄区域列出已选块序和插入位置，右侧显示彩色候选块。四方向键选择候选块，Shift＋左右键调整块序位置，Enter 直接插入；添加后可以立即继续定位或选块，无需切换区域。序列下方显示当前选中块的旋转系统、名称和形状：方向键浏览候选块时显示候选块的信息，Shift＋左右或 Home / End 定位序列时显示该位置的块，插入后显示刚插入的块。

P 键直接进入与普通设置相同的界面。「出块方式 = 旋转系统」的条件设置「旋转系统」不缩进，并打开标准选项列表，上下选择，Enter / 右确认，左 / 退格 / Esc 取消。「旋转系统 = 愚人节2026」的子设置「初始楼层」使用 1～10 的数值输入；自定义块序的「方块库」用于选择候选块的系统。宽度和高度各自打开标准变量输入行，Enter 确认，Esc 取消，留空保留原值；修改只影响地图草稿。按 `/` 输入搜索词可跨全部旋转系统检索，支持名称、系统名称、编号及多个关键词，如 `PENTOMINO I`、`20260401 T3`、`#173`；全角、半角字母都可检索。

长块序随插入光标滚动，用 `↑ …` / `↓ …` 提示被省略的部分；终端过窄时，已选序列改为候选区上方的一行，追加时只显示末尾若干块，前方用 `…` 提示。候选区根据可用宽、高分页，形状超出卡片或内容区时裁剪，不覆盖其他方块和底部操作提示。

固定旋转系统方案按所选系统和现有随机方式持续生成方块。愚人节2026只加入第 1 层至指定初始楼层（含该层）的特殊块。自定义块序允许混合所有旋转系统中的方块，包括愚人节各层的特殊块；使用地图后，「游戏机制 → 方块 → 旋转系统」新增「自定义」选项，默认沿用每块原有的形状和旋转定义。可以重新选择其他旋转系统：有对应名称、相同形状的方块会换用该系统的定义，没有对应定义的特殊块保留原旋转；块序顺序和已保存地图保持原样。该选择单独存于玩家配置 `[MAPS] Rotation System`，`-1` 表示「自定义」，普通出块的旋转设置仍可独立配置。重新使用地图会恢复「自定义」。机器人仍受其已有方块支持范围限制，不兼容的自定义序列会使该机器人不可用。

自定义块序是有限序列，预览只显示尚未用完的块，不填充随机块。所有块被放下后结束游戏；序列用完但 Hold 尚有一块时，自动取出并继续操作，放下最后一块后结束。最后一块且 Hold 为空时，不能把它存入 Hold 而跳过放置。无目标时空序列直接完成；设有目标时按下述目标判定。顶出等其他结束条件仍然有效。

## 自由游玩的地图目标

「模式 = 自由游玩」中可选择普通目标，选用地图后额外显示「消除初始格」：

- **无**：没有额外目标；有限块序用完后正常结束。
- **消除初始格**：清除开局版面上全部已有的格子后结束，允许还留有后来放下的方块。初始格子的身份随消行、垃圾上升、撤销及回放保留；初始版面本来为空时直接达成目标。
- **全消**：实际 ALL CLEAR 次数达到设置值后结束。该目标独立于全消攻击奖励开关；开局为空本身不计一次 ALL CLEAR。

地图编辑的 P 键菜单可设置默认地图目标，默认关闭。「使用地图」时，关闭保留当前目标，消除初始格或全消则更新当前目标；全消设为 1 次。该操作不改变游戏模式，随后可以手动修改目标。取消地图时移除旋转覆盖，并将消除初始格目标恢复为无；普通场地和出块设置保持原值。自定义块序耗尽而目标尚未达成时，本次挑战结束为失败；Hold 中最后一块仍会正常放出。

左侧数据在消行完成后更新，包括达成目标的最后一块，显示消除初始格子数 / 初始总格子数或 ALLCLEAR 次数进度。普通目标显示相应计数或时间倒计时。三秒倒计时每次数字更新会恢复其空白处的场地；结束时恢复整个数字覆盖区域，并遵循方块隐藏规则。

## 保存格式与回放

所有地图存于 `.tetr/maps.txt`，玩家配置的 `[MAPS] Selected` 保存所选编号。文件头记录格式版本和下一个编号；每张地图独立保存编号、名称、尺寸、生成方案、旋转系统、楼层、默认地图目标及块序。不同地图可同名，删除只移除指定地图，剩余地图按顺序从 1 重编号，同时更新玩家配置中的选图编号。

场地行采用[俄罗斯方块中文维基的绘制场地格式](http://tetriswiki.cn/p/俄罗斯方块中文维基:绘制场地)：`{{pfstart}}`、由上到下的 `{{pfrow|…}}` 和 `{{pfend}}`，空格表示空格子，`G` 表示垃圾灰，`I/J/L/O/S/T/Z` 表示七种方块颜色。例如：

```text
TETR_MAPS 1 2
[map 1]
Name = "地图1"
Size = 4 2
Generator = sequence
Rotation = 0
Floor = 1
Goal = 0
Sequence = 173 178
{{pfstart}}
{{pfrow| | | | }}
{{pfrow|G|T| | }}
{{pfend}}
[/map]
```

地图文件的 `Goal` 为 0（关闭）、1（消除初始格）或 2（全消）；旧文件省略时按关闭读取。选择地图后，默认目标为关闭时保留当前目标；默认目标为消除初始格或全消时自动更新自由游玩的目标，全消目标设为 1 次；之后可以手动修改。“消除初始格”仅在选用地图时显示，取消选图或删除所选地图后恢复为无。玩家配置 `[MODEL] Goal` 和回放分别保存实际目标。

`Generator` 可为 `rotation` 或 `sequence`；`Sequence` 使用项目方块目录编号，保留各系统的具体方块定义。保存采用临时文件替换，损坏的地图集合不会被新地图覆盖。测试可用 `TETR_MAP_FILE` 指定独立集合路径。

结算界面按保存回放键后，Esc 取消本次保存并留在结算界面；松开后重新按 Esc 仍可返回开始界面。

原生回放嵌入该局实际使用的地图和旋转选择，后续编辑、删除或移动地图文件不影响回放恢复场地、块序和旋转定义。
