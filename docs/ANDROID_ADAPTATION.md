最终交付物是可直接安装的 **`dist/android/TerMino-android-preview.apk`**；源码工程在
`android/`，属于配套开发材料。当前 APK 使用本地 Android debug 签名，供安装验证，
尚未进行应用商店发布或真实 ARM64 手机的体验验收。

继续遵守 [维护约定](../CONTRIBUTING.md)、[共享前端边界](FRONTEND_MIGRATION.md) 和
[基线恢复规则](FRONTEND_BASELINE.md)。Android 复用 Runtime/Rules/Engine/App/Replay/

桌面个人 `.tetr` 未用于 Android 调试；安卓数据位于应用私有 `files/.tetr`。

## 使用与交互

- 手机/平板采用两个横屏方向，按安全区换算触摸与绘图坐标。
- 手机使用完整窗口高度，页面按实际安全区宽度重新排布；文字、按钮和地图格子使用
  同一缩放比例，不再把桌面 1200×800 画布分别横向、纵向拉伸。安全区继续避开刘海与系统边缘。
  手机菜单、文字、棋盘和统计额外放大约 15%，编辑器空场地略增大；固定左栏按键及虚拟游玩键保持原尺寸。
  双人及多人对战不再预留桌面键盘提示栏，按左右对称的窗口范围居中；游玩左栏只悬浮覆盖，
  展开或收起不会挤压、平移棋盘。布局计算包含放大的反向换算，较窄横屏也保留完整的两侧面板。
- 对仍偏小的说明、状态和统计标签设置更大的手机字号下限；文字测量、换行和裁剪使用同一字号。
  实战统计同步增加标签与数值间距；固定左栏按钮及虚拟游玩键尺寸保持原有布局。
- 设置原“键位设置”位置已替换为“虚拟按键”。桌面两个前端保留原键盘绑定。
- Android 设置页移除方向键、Enter、Backspace、Esc、R/P 等桌面操作提示及页脚，
  确认、取消、保存等说明按触摸页面表达；选项内容、确认次数和键盘操作语义不变。
- 十一个可编辑动作：左移、右移、软降、硬降、顺转、逆转、180°、暂存、暂停、重开、撤回。
  每个键分别编辑中心 X/Y、宽/高、不透明度、旋转角、形状、圆角、层级、启用和玩家。
  矩形、圆角矩形、椭圆、自定义简单多边形均按真实边界绘制/命中。
- 默认布局参照双拇指圆形按键：左侧为旋转与暂存，右侧为移动与软硬降，暂停/重开
  与撤回位于上方。已有自定义布局不会被升级覆盖；编辑器左栏“默认布局”可恢复新布局。
- 游玩按键使用直接绘制的线条图标，不显示动作文字、F1 或 F2。左右移为尖括号，
  软降为向下尖角，硬降增加落地横线，旋转为环绕方块的有向箭头，暂存为方块与托盘，
  暂停为双竖线，重开为带播放标记的环形回转箭头，撤回为向左回转箭头。
  按当前玩家、规则、Bot 和会话状态禁用的动作显示为灰色且不响应触摸；失效动作的在途触点会释放。
  图标随按钮旋转、尺寸和透明度变化。
- 编辑器中央固定显示 **10×20 的空场地**，使用正方形格子，不显示实战方块、
  HOLD、NEXT 或统计。属性面板默认收起，有独立关闭按钮，移动/缩放/编辑顶点期间隐藏。
  选中按钮中心位于安全区左半边时面板在右侧，反之在左侧并避开固定工具栏；
  切换按钮或拖过中线后自动换边，绘制、数值编辑与关闭命中区使用同一位置。
- 拖动改位置，方形手柄改宽高；属性面板在对应属性后就地输入。首次输入会替换当前数值，退格
  可清空；固定“应用”先接受当前数值，再次应用保存整个布局。返回取消当前输入或草稿。
  顶点输入格式为 `x,y;x,y;...`；可以拖动顶点，非法/交叉/零面积多边形不能保存。
- 编辑器接管物理键盘和软键盘确认，输入不会同时触发底层设置页；离开编辑器后恢复共享键盘输入。
- “上一个键 / 下一个键”可重新选中透明、禁用或被遮挡的键；“添加/复制”允许同动作
  多个按钮。默认布局、删除、切换玩家、启用/隐藏均在左栏中直接提供。条目超出高度时纵向滑动，
  不再分页或显示“更多操作”；全部删除后仍可恢复。
- 安卓设置列表每行从 44 增至 62 个逻辑单位，主列表显示七个完整条目，文字与数值同步放大；
  列表滚动和就地编辑命中区按新行高一致计算。桌面菜单保持原行高和字号。
- 开始和设置页直接复用桌面图形版菜单；数字/字符串设置在原选项后
  编辑，不另开手机专用输入页面。输入法请求单行确认动作，禁用自动纠错与自动大写；
  再次点击当前输入框只重新唤起键盘，不退出编辑。固定“确认”同样可提交。
- 菜单与祖先列表保留小数滚动位置；手指移动时逐次更新，松手不会变为整页跳转。
  桌面图形版同时支持连续滚轮、手指拖动与鼠标拖动滚动条，键盘仍能自动显示焦点项。
- 结算概览、挑战成绩、玩家列表和消行统计使用小数位置的连续滚动，手指移动时逐次更新，
  抬手保留位置，不按整行或整页吸附。顶部直接点击统计总览、消行统计和可用的挑战成绩；
  玩家卡片、指标行、概览卡和消行单元格直接点击选择/高亮，合计也可选。左栏不再提供
  统计切页、玩家上一页/下一页和四向逐项选择按钮。消行表支持纵向滚动和宽表横向拖动，表头、合计与
  当前选中数值保持可见；大计数在下方完整展示，不靠缩成小字。键盘逐项/翻页操作继续显示焦点项。
- 固定左栏仅显示当前控制器接受的键盘操作；例如普通设置的重开/退出不再出现在地图选项、
  只读设置、输入框或其他独立选择页。文本编辑只显示返回、确认；单窗口双人设置增加
  “切换对象”，复用原 Tab 的玩家 1 / 玩家 2 / 双方切换；可切换焦点的观战场景也复用原 Tab。
  左栏横向紧贴屏幕左边缘，纵向沿用安全区，栏内按键和菜单开关的绘制、触摸共用同一边界。
  游玩、结算棋盘和虚拟键编辑期间默认隐藏，点击左上角菜单按钮展开。
  从游玩进入结算、进入或退出虚拟键编辑时重新收起；设置、文本、统计和地图页面仍显示各自的固定控件。
  游玩左栏按可用性提供重开、设置、退出及房主管理等操作；结算左栏提供重开、设置、退出，
  下方的统计、保存录像和导出录像在对局结束后立即出现，与左栏展开状态无关。统计、地图及回放保留各自的专用操作。游戏和回放的操作仍受原规则与当前阶段限制：
  例如录像保存沿用共享结算流程，在对局结束后使用，挑战的禁暂停规则不被绕过。
- 从游玩页进入虚拟键编辑器会先进入共享设置流程；关闭该流程沿用原产品的返回开始页
  行为。编辑时不会向对局发送拖动/按键操作。
- 回放速度/进退、统计页、房主结束对局等使用固定页面控件；回放的暂停按钮不读取
  游玩键布局。地图画布保留直接触摸绘制，页面导航可用固定左栏。
- 单窗口双人录像共用一个播放时钟与控制输入读取器。手机左栏暂停/播放、桌面任一
  玩家的暂停键和空格均同时控制双方；倍速与前后跳转保持同一时间线。共享修复同时
  用于终端、桌面图形和 Android，不改变录像格式或实战对局的暂停限制。
- 回放从系统文件选择器导入，Android `content://` 先读为应用私有临时文件交给共享解析器；
  导出使用系统保存文件对话框，导出最近保存的录像。取消不会改原始录像。
- 三平台初始库统一包含用户明确指定的 24 张地图和 4 个预设（含“下棋模式”）。
  发行源位于 `resources/defaults/`；桌面安装组件从该目录复制初始库，APK 将其放入 assets。
  Android 仅在相应库文件缺失时初始化，写入完成后原子改名，不覆盖已有地图或预设。

## 构建安装包

需要 Python 3.12+、JDK 17、Android SDK Platform 35、Build Tools 35.0.0、NDK
28.2.13676358、SDK CMake 3.22.1。Gradle 8.12 / Android Gradle Plugin 8.7.3 固定于工程；
wrapper 带分发校验值。本机已在用户目录安装所需工具和 Android Studio；命令行构建不依赖 IDE。

```sh
source "$HOME/.local/share/termino/android-env.sh"
python3 tools/check_android_environment.py --strict
python3 tools/build_android.py
```

脚本校验/下载固定 SDL 3.4.18、FreeType 2.14.1 源码，调用 Gradle 构建双 ABI 通用包，
检查 APK 签名、ZIP/ELF 16 KB 对齐、必要资源和无个人数据后写入 `dist/android/`，
同时输出 `.apk.sha256` 和 `.audit.json`。依赖位于忽略目录 `build/android-deps/`，
原生构建在 `build/android-gradle-native/`，不会改变桌面 `build/tetr` / `build/tetr_gl`。
首次构建需要网络下载 SDK/Gradle/原生依赖；签名密钥由 Android 用户目录管理，不入仓库。

```sh
# 已有 SDK/JDK 时也可明确传入路径；Windows 使用 Python 和同一入口。
python3 tools/build_android.py --sdk /path/to/Android/Sdk --java-home /path/to/jdk-17
python3 tools/build_android.py --audit-only dist/android/TerMino-android-preview.apk
# 只下载/核验 graphics 源码，不构建或访问设备。
python3 tools/build_android.py --prepare-only
```

包名 `io.github.candy0014.termino`，最低 Android 8.0 / API 26，目标 API 35。
包含 `arm64-v8a` 和 `x86_64`；通过 Android 安装器安装 APK。安装不要求任何桌面文件夹。
`adb install -r` 只能在明确指定的测试设备上手动运行，构建脚本不连接设备或自动安装。
发布签名、AAB、商店分发另行处理，本轮未推送或发布。

手机尺寸/图标调整时的本机调试证书与最初预览交付包不同，覆盖最初版本需要其签名密钥。
左栏贴边版本沿用上一版调试证书，已在独立测试模拟器内验证覆盖安装；未卸载旧预览安装或清除其数据。

本次直接触控版本使用现存的本机 debug 密钥（证书 SHA256 `f2b5d14f…ede3f`），与上一版
验收记录的 `e59aa7f8…a11a` 不同；未找到匹配旧证书的私钥，用户亦确认没有另存密钥。
因此当前 APK 已验证独立安装，但不能承诺覆盖旧证书签名的安装。没有卸载或重置用户应用/数据。

## 源码与输入边界

- `src/frontend/android/`：入口、应用生命周期、系统文件/输入法接入及触屏页面。
  JNI/SDL 保留在平台前端；渲染复用 OpenGL 前端并选择 GLES 3.0 shader。
- `include/tetr/frontend/virtual_controls.h` / `src/presentation/virtual_controls.cpp`：
  不依赖 SDL/GPU 的布局、几何、真实形状命中和多指归属。
- `src/config/virtual_controls.cpp`：布局编码、验证和合并保存；不覆盖玩家、图形或其他字段。
  错误版本、未知属性、坏 JSON、非法几何保留原文件并拒绝保存，不静默改写。
- `(touchID,fingerID)` 在按下时捕获按钮，直到抬起/取消；每玩家/动作计数，两个手指
  同键时松开一个不会释放另一个。不同玩家使用独立内部动作码，不保存到键盘绑定中。
  触摸和物理键分别持有；旋转、DAS/ARR/DCD、预输入、软硬降仍由共享引擎处理。
- 使用原纳秒触摸时间，经现有有序输入边界提交；输入采样不等待绘图或 VSync。
  页面/布局/安全区变化、失焦、后台均清理触点；关闭 SDL 触摸模拟鼠标，避免双触发。
- SDL 进入后台前收回绘制线程的 EGL 上下文，Surface 恢复后重新建立渲染资源；
  不复用失效 Surface。后台不会更改挑战暂停限制或联机时间规则。
- Android 不访问桌面 evdev/PulseAudio。声音使用 SDL Audio；WSS 使用交叉编译 curl/
  Mbed TLS 和包内 Mozilla 根证书，保留主机名/证书链验证。浮点严格解析由固定
  fast_float v8.3.2 补足 NDK 的 `std::from_chars(double)` 缺项，桌面解析实现保持原有路径。
- Android 的会话、Bot 搜索和本地双人工作线程通过 `Util::WorkerThread` 显式保留
  16 MiB 栈，避免原有按值传递完整版面的调用链耗尽默认栈。Android 15 x86_64 实测
  原默认线程栈为 1 MiB；修复前已复现崩溃，修复后十种 Bot 各完成至少五次自动落块。
  普通对局、Quick Play 异步搜索及 ChatGPT 手感模拟分别验证。桌面仍使用标准线程。
  预览 APK 的原生代码也启用 `-O2`，保留调试符号，避免无优化搜索造成长时间等待。

## 布局数据契约

`.tetr/config.json` 的独立 `virtual_controls` 子树为版本 1，参见
[JSON Schema](android/virtual_controls.schema.json) 和 [十一动作示例](android/landscape_controls.example.json)。
布局保存动作 ID，只允许上述十一种游玩动作；设置、保存录像等页面命令不写入按钮动作。
中心坐标相对于当前横屏安全区宽/高；宽和高分别以安全区短边为单位，范围 `(0,8]`；
不透明度为 `[0,1]`，旋转角为 `[-180,180]`，圆角半径为按钮短边的 `[0,0.5]`。
多边形使用按钮局部 `[0,1]` 有序顶点，3–64 个，必须为非退化简单多边形。

每个布局最多 256 键、文档最多 32 布局；按钮 ID 在布局内唯一，布局 ID 在文档内唯一，
活动布局必须存在。支持相同动作多个按钮和玩家槽 0/1。重叠按层级、后项优先命中。
透明度 0 的启用键仍能触摸；禁用键不响应。展开后的固定左栏优先于游玩键，编辑器默认只显示左上角开关。
当前编辑器编辑活动布局；其他布局可保存在文档中，但没有布局库管理界面。
默认布局为玩家 1；本地双人可复制按键并切换为玩家 2，各玩家动作不会串线。
