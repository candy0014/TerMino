# 图形前端视觉改造（2026-10-17）

2026-10-21：设置现采用祖先菜单与宽当前面板，鼠标点击直接操作共享控制器，并修复近期回放。详见 [本次变更与验证](SETTINGS_REPLAYS_20261021.md)；下文保留此前改造记录。

这轮改造覆盖首页、完整设置树、选项列表、数值/文本编辑、改键、地图编辑、赛后统计、联机等待以及单人/多人棋盘。
图形设置不再逐格绘制终端菜单，而是读取共享控制器输出的语义信息，独立安排字体、
控件、留白、焦点、说明和滚动位置。游戏规则、设置验证、保存、网络和回放仍只有原有实现。

## 画面与交互

- 首页使用大标题、几何方块构图和三个明确入口。当前玩家与模式来自实际配置。
- 设置首页提供分类导航和分类内容预览；子页采用参数控件、当前位置和说明栏。
  布尔参数使用开关，选择参数显示当前值，数值与文本使用可编辑输入框，按键以独立绑定项显示。
- 分类导航、标题、内容列和页脚共用固定位置。普通参数和改键保留所属菜单并在原行编辑；
  顶层预设命名保留分类栏与预览区标题。长列表只在焦点离开视区时滚动，返回时保留位置。
- 棋盘结束页和统计页的回放保存使用独立图形对话框，显示默认路径、输入光标及键盘提示。
  Enter、Esc、中文/空格路径和保存后返回统计页仍由同一个共享控制器处理。
- 长选项列表跟随键盘焦点滚动；中文、长路径、当前值、禁用状态、双方不同值、
  预设未定义值、恢复确认和联网状态由共享模型提供。地图列表保留棋盘预览。
- 输入框按 UTF-8 字节光标定位，超长内容随光标滚动；输入法组合串及候选区域跟随图形输入框。
- 全部原键盘操作继续生效。首页/菜单/选择器允许鼠标点击，滚轮等价于上下选择，
  返回按钮等价于左键。鼠标请求绑定当前页面并经过原导航输入；失焦、物理按键、
  页面切换和请求超时会取消未完成请求。改键期间鼠标不会产生可被绑定的假按键。
- 单人、双人和观战继续消费同一个 `BoardView`。方块采用克制的明暗面、细高光和清晰的落点轮廓。
  主棋盘省去没有信息的高位存储行；有方块、提示或特殊块的高位行仍完整显示。
  单人和多人棋盘不绘制顶部边框、顶部横线及隐藏行网格，出生与溢出区域保持开放。
  没有加入震屏、粒子、拖尾、消行动画等待或输入延迟。
- 字形按实际像素尺寸缓存，使小窗口中的中文字形与大标题均保持可读。
- 焦点与输入框描边至少保留一个实际像素，避免缩小窗口后横线消失。

后续完成了此前保留的兼容画布页面：地图编辑器使用原生网格、颜色工具、跟随光标的视区、
候选块卡片与块序列表；退出确认和检索使用图形对话框。统计使用指标卡片、彩色消行表格、
固定合计行列、玩家列表和挑战成绩卡片；房间等待使用成员列表、准备人数、容量与开始控件。
连接状态和回放提示使用独立提示卡片。窗口大小不会限制共享模型中的指标、计数或成员数量。

单人、双人与完整房间棋盘把时间、分数、PPS/APM、攻击、连击、消行、快速游戏进度、
阶段任务和事件放在左栏；窄栏将并排指标改为纵向排列，数值完整显示，长任务与通知换行。
右侧只保留 NEXT；底部按键块直接读取实际绑定，不解析终端提示字符串。
子页左侧分类栏目前表示所在分类，切换分类仍先返回上一级；未加入鼠标直接跨分类跳转。

## 实现边界

`Frontend::UiMetadata` 新增本地化标签、值、控件类型、说明、上下文、祖先路径、
输入文本/光标、快捷键和地图预览。它们都是值类型，不包含平台句柄、可变设置引用或图形库类型。
`settings_view.cpp` 从原设置树构建这些投影，继续维护原终端画布。
`parent` 保留编辑中的所属菜单值快照；回放保存从共享应用层补充语义元数据，终端布局与保存逻辑保持原实现。

`menu_renderer.cpp` 独立绘制语义菜单；`scene.cpp` 绘制对局；`renderer.cpp`
负责图形与字形；`application_renderer.cpp` 绘制编辑器、统计、房间与提示卡片；
`menu_pointer.h` 把鼠标快捷入口送入已有导航输入。
新增的 `UiMapEditor`、`UiStatistics`、`UiLobby` 都是无平台值快照，包含完整计数和逻辑焦点；
仅在启用语义 UI 接收端时生成，终端不承担图形投影的复制开销；
块序仅投影插入位置附近的可见项目，并携带总长度和起始索引，避免十万块序的全量几何复制。
候选网格的列数和分页大小来自共享键盘控制器，方向键与 PageUp/PageDown 不会与图形排列错位。

OpenGL 的逐单元格字符/边框兼容绘制已删除，输入法定位只使用实际图形输入框。
新应用页必须提供语义模型；缺少模型的非空字符帧会明确报错，不能悄悄退回字符界面。
共享应用仍通过 `TerminalCanvas` 同时维护终端输出和语义投影，本次不宣称已经彻底移除终端适配层耦合。
终端布局、输入处理、规则、保存、协议与回放继续使用原实现。
`tetr_gl_renderer` 只在启用 OpenGL 时构建，终端和无界面目标不需要 SDL/OpenGL/FreeType。

视觉参考包括 [TETR.IO](https://tetr.io/about/)、
[Tetris Effect: Connected](https://tetriseffect.game/)、
[Techmino](https://github.com/26F-Studio/Techmino)，以及本地 `termino-2077` 的深色科技感。
页面、几何构图与控件由本项目实现，没有导入这些作品的图形资源或玩法代码。

## 隐藏截图检查

编译 `graphical_visual_test` 后，显式指定字体和输出目录。该工具创建隐藏窗口，
通过真实共享会话操作菜单、修改参数、改键、输入中文、预览地图、落块、暂停和本地双人，
生成 19 张实际渲染截图，包括进入手感分类/参数编辑前后、预设命名、棋盘保存取消和统计页中文路径保存。
运行数据写入输出目录中的唯一临时子目录。

```sh
cmake --build build --target tetr_gl graphical_visual_test -j 2
SDL_VIDEODRIVER=offscreen ./build/tests/graphical_visual_test \
  resources/fonts/NotoSansCJKsc-Regular.otf /tmp/termino-visual zh
SDL_VIDEODRIVER=offscreen ./build/tests/graphical_visual_test \
  resources/fonts/NotoSansCJKsc-Regular.otf /tmp/termino-small zh 840 560
```

它不注册为无窗口 CTest，以免把驱动可用性误当成纯逻辑测试。图形导航、数据持久化、
失焦、鼠标请求取消和隐藏行范围检查由现有图形契约测试覆盖。

首轮验证记录位于忽略目录 `build-migration-backups/modern-ui-20261017/`；
原位编辑与 DAS 调查位于 `modern-ui-followup-20261017/`，续作最终记录与预览图位于
`build-migration-backups/modern-ui-resume-20261017/`。
