# Bundled fonts

The default graphical font is **Noto Sans CJK SC Regular**, from the official [Noto CJK Sans 2.004 release](https://github.com/notofonts/noto-cjk/tree/Sans2.004). File: `Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf`.

- SHA256: `2c76254f6fc379fddfce0a7e84fb5385bb135d3e399294f6eeb6680d0365b74b`
- License: [SIL Open Font License 1.1](LICENSE-Noto.txt), copied from the same upstream tag.
- Full upstream font retained for menus, Chinese usernames, paths and map/preset names; no runtime font download.

The phase-two DejaVu Sans fallback and its original `LICENSE-DejaVu.txt` are retained. `--font FILE` selects a custom font. Both font licenses are installed with the graphical resources.
